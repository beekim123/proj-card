# 本体第2批 Godot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. 用户已选择由Dot开发；在同一会话按顺序执行，步骤用复选框记录，不默认增加子代理或计算worker。

**Goal:** 在当前Godot第一幕工程上交付12仗、去留、收藏室的第二批可玩代码。

**Architecture:** 原有纯规则模块负责结算、命令和快照，新增纯收藏模块；存储适配器原子提交收藏/纪录/回执；原生界面只调用这些接口。新内容加入原有配置和效果注册，不复制第二套战斗引擎。

**Tech Stack:** Godot 4.7.2 stable，typed GDScript，Compatibility，现有Node/Python维护工具，无插件。

**Spec:** 本包 `00-开发说明.md`、`01-规则与数值.md`、`02-界面与代码接入.md`、`03-存档与回归策略.md`、`内容配置.json`；验收依据 `04-验收清单.md`。

## Global Constraints

- Godot **4.7.2 stable**、有类型GDScript、Compatibility；不装插件。
- 第三幕、加码、最后4件宝物、大宝石完整通关不进入本批。
- `h5/`、旧oracle/golden及冻结指纹不修改；不接入本轮美术返稿。
- 全机最多2个耗资源任务、2个计算worker；本计划默认单worker、顺序测试、数值库线程1、长计算 `nice -n 10`。
- 图形测试实时识别Mac内屏；不能假定屏幕0或历史坐标。纯headless无需定位。
- 横屏1920×1080；保留竖屏1080×2160逻辑画布在1080×1920窗口等比显示。
- 本包中的新接口/新测试代码是待实现合同，未把它们预装进当前生产代码。
