# 新卡牌 · 本体第2批 · Godot 开发包

日期：2026-11-11。执行方：Dot。状态：开发要求已整理，功能尚未开发。

本批把当前可玩的第一幕扩展为两幕，并做出“带着宝物回家／接着追”和收藏室。用户本轮要求整理开发包、提交推送，代码功能由 Dot 开发。美术先不处理；为新key补齐原生占位映射，不等待返修。

## 1 从哪里开始

仓库：`https://github.com/beekim123/proj-card`，交接分支：`main`。本包在仓库中的固定入口：`docs/development/body-batch-2/00-开发说明.md`。

先读根目录 `README.md`、`HANDOFF.md`，再依次读本包 01–05。当前可执行基线是根目录 Godot 工程；`h5/` 是冻结参照，只读。第一幕的挑门、三类门奖励、工坊、排牌再打出、练习、设置、声音和文件存档已存在，沿用这些行为。

本包的规则细则优先于旧总方案中尚未落实或含糊的描述；旧总方案位于 `h5/design-docs/本体内容方案.md`，数值模拟参考在 `h5/design-docs/模拟/`。模拟器中的试验开关、策略和名字不直接作为正式 API。

## 2 这批交什么

- 第一幕门厅＋第二幕长廊，每幕6间，共12仗。
- 新怪3只：弹簧盒、画像、大挂锁；新规矩3条：缩头、挑食、限六张。
- 第二幕宝石龙的三层规矩：挑食 → 缩头 → 限六张。
- 新牌3种：调色盘、药水、钻石；额外牌总数9→12。
- 新宝物5件：红／绿／蓝宝石加倍、顺色×3、同色×4；宝物总数10→15。
- 第一幕龙后拿宝物，再选带走或继续追；第二幕龙后拿宝物，本批到此带走，不把它记作完整本体通关。
- 收藏室：初始6件；安全带回才加入收藏；开局从已收藏宝物抽3选1，局中奖励可抽本批全部15件中尚未持有的宝物。
- 原生界面、规则说明、调试入口、存档升级、真实文件持久化和验收证据同步完成。

## 3 本批边界

第三幕、摇钱树、盔甲、长回去、压倍率、剩余4件宝物、加码、大宝石最终通关留给第3批。收藏室不提供永久数值加成。沿用现有工坊，不增加金币商店、地图、改色、每日挑战等系统。

用户已明确只做 Godot；不恢复 H5 或小程序开发。不改 `h5/`、原美术、字体和音效源码，不在本批更换渲染技术或重导整套精灵图。占位素材的新增 key 见 02；不把占位写成美术验收完成。

## 5 环境与资源限制

Godot **4.7.2 stable**、有类型GDScript、Compatibility；不装插件。Node维护脚本按现有环境运行，完整基线检查不需要安装H5依赖。引擎二进制、`.godot/`、`artifacts/`、`exports/` 不在Git里；接收方自行提供4.7.2，并设置 `GODOT_BIN`。

```sh
export GODOT_BIN='/接收机器上Godot4.7.2的实际可执行文件'
bash tools/import.sh
bash tools/check.sh
bash tools/run.sh --debug
```

`tools/import.sh` 在隔离镜像导入，防止编辑器写入H5。macOS图形运行沿用实时内屏识别；不能假定屏幕编号或坐标。无法定位内屏时先完成headless检查，不擅自开到外屏。

同一台机器所有聊天合计最多2个耗资源任务、2个计算worker；本批默认顺序单worker，数值库线程为1。启动前检查其他会话计算进程；有依赖的测试、导图、打包不并行。长计算用 `nice -n 10`，不要使用 `nohup`、`disown` 或后台堆任务。当前包不要求重跑昂贵的整手规划模拟。

## 7 审查修订与用户决定

2026-11-11 独立审查后补定了6处合同，开发时以修订后的文字为准：带走的终局阶段、`monsters` 与龙规则的存放（01 §1）、限六张的统一判断接口（01 §2）、调色盘等“桌上宝石位可变”的牌（01 §3）、纪录 `farthest` 新编码（03 §3）、第一幕旧黄金的 `LEGACY_RUN` 回放（03 §4）。另补了漏列的改动点（02 §3）。

1. **已定（用户 2026-11-11）：所有活动阶段都保留“放弃这局”，包括龙奖励和去留阶段。** 放弃一律判 `defeat`，本趟新宝物不入收藏，已有收藏和旧纪录不变。沿用现有放弃入口和二次确认，不另加限制。

2. **已定（用户 2026-11-11）：接受初始收藏6件带来的开局难度，本批不调整。** 依据：定向模拟（单进程，跟提示·乱拿，400局，误差约±5个百分点）：开局池用原10件时第一幕通过率48.3%，改为初始收藏6件后42.8%，两幕通关8.8%；试20种·会拿两幕通关87.7%（300局）。比原方案“新手一半能过第一幕”略低。初始收藏按01 §5的6件实现；是否调整留到真人试玩之后再定，Dot不要自行改初始收藏或血量。
