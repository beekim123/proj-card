## B 跨幕与收藏

- [ ] B01：第一幕龙后先回心、选宝物再去留，领取前/领取后各恢复一次，候选不重抽、不漏发。
- [ ] B02：带走只结算一次；收藏并集去重；下次开局只从收藏池抽，初始池确为6件。
- [ ] B03：继续进入第二幕第1间，不清成长/牌组/宝物；第二幕失败不带回本趟新物，旧收藏不丢。
- [ ] B04：第二幕龙奖励后只可带走，最多持有5件；不越界进第三幕、不记录完整通关、不开放加码。
- [ ] B05：精英/龙奖励可选未收藏宝物，但排除本局已有；收藏顺序不影响固定种子抽签。
- [ ] B06：新开局、继续旧局、练习相互隔离；练习药水无虚构心数，消费和撤回规则一致。
