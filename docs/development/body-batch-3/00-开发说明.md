## 3 本轮明确的规则决定

以下两条由用户在2026-11-11本聊天明确选择“按这两条写”：

- **压倍率**：进入该层后，下一张牌就以最高×32结算。不能沿用旧模拟器“先按旧高倍率伤害、最后只钳下一倍率”的漏洞。跨层当张仍按出牌前规矩，详见01。
- **挡一次**：在精英奖励取得后，本幕立即有一次抵挡；进入下一幕重置。不能等到下一幕才开始生效。

其余内容按现有本体总方案的第三批范围细化。旧总方案在 `h5/design-docs/本体内容方案.md`，本身仍带“等拍板”的历史抬头；不要把它的每个模拟实现细节写成用户已决定。本包对取整、生命周期、存档和统计的明确合同优先于模拟器；来源冲突与解释见01。没有重新调数值，也没有宣称三幕平衡已验收。

继续遵守第二批用户已定事项：初始收藏6件及既有血量不自行降低；所有活动阶段保留“放弃这局”，放弃判defeat，本趟新宝物不进收藏。

## 5 开工与资源

Godot **4.7.2 stable**、typed GDScript、Compatibility、无插件。引擎和缓存不在Git，接收方提供并设置 `GODOT_BIN`。

```sh
export GODOT_BIN='/本机Godot4.7.2的实际可执行文件'
bash tools/import.sh
bash tools/check.sh
```

导入通过原生隔离镜像；不对含H5的根目录直接启动编辑器导入。Mac图形窗口必须实时识别内屏并以DisplayServer验证坐标，不能复用历史屏幕号。不能可靠定位时先做无窗口工作，说明缺口。

全机所有聊天合计最多2个耗资源任务、2个计算worker；默认单worker顺序执行，数值库线程1，长计算nice10。启动前及长任务期间核对全机可见进程/内存；不按CPU核数扩并发，不用nohup/disown或后台堆任务，不动其他会话进程。无需重跑旧昂贵整手规划模拟；本包没有把历史模拟胜率当新结果。
