# 异能卡牌 · 恐怖夜林试玩

Mac 内置屏幕全屏，Electron + 原生 JS + 单 Canvas。双击 **启动.command**；或在仓库根目录运行 `npm start`。新克隆先 `npm ci`；不需要启动网页服务器。⌘Q 或大厅「退出游戏」关闭。

**当前场景：** 只保留原来的 2D 仿 3D 夜林。探索时最多向下微倾 4°，能抬头到正上方；按 W 沿前方走，松开仍可停步。近处是流动薄雾，远林更浓，手牌与文字不蒙雾。

**第一次建议：** `npm start -- --seed=1200`。点左侧「开始游戏」，先原地看水面，再按 W 朝前方浅水走约两秒；松手停步，鼠标回望。W/S 前后，A/D 横移，Shift 跑，Esc 释放鼠标，点画面重新接管。只有实际走过的距离会触发遭遇。音乐和音效可在大厅分别调节和静音，首次点按后声音开启。

**打、捡、收藏：** 点怪物或名牌定目标；选中有四角金边，悬停另一只只查看。把手牌拖入序列，最多五张，可插入、换序、拖回手牌。按「施法」后序列收起，目标头顶亮阵。同色、相邻、对面、百搭可连倍率；白光对厚皮无效，躲光按回合初灯数减伤。怪物散尽后点画面接管，走近地上的牌、准星对准，按 E 或左击；三选一也可以不要。每四仗仍为精英，封印或放走后回一心。撤离或失败后「再来一局」回到大厅。卡册不改掉率，只记录拿到的牌。卡册（第三版，2026-11-20，见 `src/album/README.md`）→ 单独一页、通用背景，一排石板牌左右滚，正中放大带倒影，换章：全部 / 色光 / 法术 / 封印；点正中的牌拿出来细看，封印牌可以试演（不是奖励）。全新存档不会伪造收藏：首次开始正式探索后，七种起手宝石会登记。不进森林也可以双击 `卡册.command` 打开独立页面。

**试玩实验（2026-11-19）：** 怪的血量压到一次施法就能打死（普通仗合计 40，精英仗 60，见 `src/config.js` 的 `EXPERIMENT`）。回归测试走原血量：网址带 `?fullhp`，Electron 加 `--fullhp`；`npm test` 在 node 里本来就是原血量。

**逃跑和回大厅：** 遇怪后点右上「逃跑」可跳过当前战斗，不给掉落、不额外扣心，之后仍可遇怪。练习中逃跑会回到选怪。场景右上「返回大厅」只暂停当前正式局，本次游戏内点「继续游戏」可接着玩；第一人称锁定鼠标时可直接按 H，或按 Esc 释放鼠标再点按钮。

**快速体验这版：** 大厅 → 战斗练习，点怪名添加、点已选位置移除，可在六种现有形态中任意组合 1–3 只。练习结算点「原样再来」会回到相同起手；要中途退出可点战斗上方「木桩练习 · 换组怪物」。练习不掉落、不写收藏、不推进正式局。月相随游戏时间每十秒变化，不读日历（大厅的调试按钮已去掉）。正常开局按种子选林地起点；从菜单走入眼前这片树林，不换镜头。

**看齐本轮的怪：** 已验证种子 `1` 的普通输入路线，四战依次可见维柯／奥鲁／巴多姆与芮娅／提可与大巴多姆。后续普通组合与牌局共用原种子流，打牌、选择不同，结果会变化；要逐点复现用下面的回放。第 1 仗三只提可的回归种子仍为 `1200`。

## 验证与维护

- 卡册第三版（2026-11-20）：照 30 包 Neo「深林碑廊」改，替换了第二版的三本小册子（旧版存档在 `CURRGO/存档/`）。`src/album/module.js` 管状态，`src/album/view.js` 画面；牌面用 `src/draw/slate-ui.js`。卡册是不透明的一页，展开后主程序不画世界（`g.album.opaque`）；`index.html`、`album.html` 的 CSP 加了 `img-src 'self' data: blob:`，石板 UI 的换色部件要用。
- 界面改版（2026-11-19）：去掉方框，按 `美术/设计/2026-11-19-美术重做建议` 的图 02–07 改了大厅、战斗、卡册；怪按体型站得更近（`WORLD.encounterDepth`），脚下加牌光和接地影；近处的树按距离压成黑剪影（`src/draw/world.js` 的 `NEAR_DARK`）。
- `npm test`：固定种子旧战斗的段数、伤害、灯、倍率、倒计时与胜利输出，另测彩虹、白光、护盾、回合上限、分块回收及水面重生。
- `npm start -- --auto`：原有 60 秒内屏 VSync 压测，实际逐帧记录写入 `artifacts/nightwood/auto.json`。可设置 `NIGHTWOOD_TEST_PROFILE` 指向单独的临时目录，避免污染个人存档。`artifacts/` 由 Git 忽略。
- `npm start -- --monster=tiko`：纯动作预览；其他 id 为 `badom`、`elite`、`veko`、`reya`、`oru`。该入口不是实战验收。
- 键鼠验收脚本使用外部 `playwright-core`，不是游戏运行依赖。本机设置 `export NODE_PATH=/Users/key_/Desktop/CURRGO/game/buttontroupe-mini/node_modules`，然后 `npm run test:forest` 录音画；`env -u ELECTRON_RUN_AS_NODE ELECTRON_QA=1 SEED=1 npm run test:live` 在独立 Electron 存档中走四仗、关闭重开查收藏。`MODE=release` 或 `MODE=fail` 验放走和失败；不设 `ELECTRON_QA` 时用系统 Chrome。`EVIDENCE` 可另指定结果目录。
## 目录分工

- 根目录的 `index.html`、`album.html` 加载游戏与独立卡册。Electron 使用 `electron.cjs`、`preload.cjs`，双击入口是 `启动.command`、`卡册.command`。
- `src/` 的 `main.js` 接入游戏页面，`game.js` 编排场景，`rules.js` 负责回合、牌组和奖励，`config.js` 集中配置，`world.js` 管投影、碰撞和分块。
- `src/battle/` 管战斗界面、拖牌、练习和怪物注册与预览。`src/dev/` 放自动跑图和自动排牌工具。
- `src/draw/` 放 UI 与渲染适配。`src/explore/` 放湿地、夜间环境，以及不消耗战斗 RNG 的怪物形态选择。
- `src/album/` 管卡册与独立启动器。`src/audio/` 放环境音、四套音乐、音效及 `试听.html`。`src/storage/` 持久化音量、曲风和收录记录。
- `art/` 放源美术和运行时资源，`vendor/` 放 p5，`scripts/` 放测试、观察与美术导出工具。

设计交回、逐件清单、源 SVG、原样备份和验收证据保存在相邻的「异能卡牌」设计仓库。不要把性能报告、单怪预览或预览截图当成胜利输入回放。
