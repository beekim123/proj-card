# 新卡牌 第一版 · 第 1 批样稿（`phase: 0`）制作说明

## 1. 各素材动画与时长

| 素材 ID | 尺寸 (`viewBox`) | 待机动画 (`idle`) | 事件动画与时长 | 核心运动部件与手法 |
|---|---|---|---|---|
| `mon_chest` | `320×400` | `2.4s` 循环（`steps(8, end)`）：箱身轻微呼吸起伏，箱盖（`#lid`）像喘气一样一开一合，长舌（`#tongue`）偶尔往外一舔，箱缝小眼（`#eyes`）微动；外框带 `0.4s` 双层手绘墨线微沸腾（`.boil-a` / `.boil-b`） | `hit`：`400ms`<br>`hit_big`：`700ms`<br>`attack`：`800ms`<br>`daze`：`600ms` 进场 + 无限循环（`infinite`）<br>`die`：`1000ms` | - `hit`：箱体往后缩倾 `6.5°`、箱盖与舌头随之轻颤后弹回，从待机或 `daze` 状态切入均自然衔接<br>- `hit_big`：箱盖砰地合拢，箱体大幅后仰 `10.5°`，切换 `#face_hurt`（紧闭痛感眼 + 框内飞溅木片），随后晃回原位<br>- `attack`：前 `20%` 蓄力张大嘴，随后冲向屏幕外玩家放大下压，在第 `400ms`（`50%`）猛然合盖咬中，再退回原位<br>- `daze`：`600ms` 进场切换 `#face_daze`（蚊香转圈眼 + 头顶浅色不发光小星），箱盖半开、舌头耷拉，随后无限循环左右慢晃<br>- `die`：箱体与箱盖散架歪斜，从口中吐出 4 颗鲜艳三色小宝石（`#gems_spill`：红圆、绿方、蓝三角），最后整体渐隐至全透明（`opacity: 0`） |
| `card_art_hammer` | `176×188` | `2.8s` 循环（`steps(8, end)`）：以右下握柄 `(124,154)` 为支点轻轻晃动，锤头正中红宝石微闪 | `play`：`600ms` | - 待机与事件只动 `#hammer`、`#gem_glint`、`#impact_lines` 3 个组<br>- `play`：先往右上后扬 `14°`，再重重往左下砸下 `-17°`，锤面处迸出放射状冲击线（`#impact_lines`），播完回弹至待机姿态 |
| `gem_red_cut` | `100×100` | `3.4s` 循环：一道斜向高光带从刻面上扫过（`#sweep_band`，裁剪于宝石轮廓内），同时右上冠部一颗小四角星（`#glint_star`）闪一下 | 无（纯待机 `img`） | - 宝石本体形状、颜色、大小、位置与上一批完全一致，不动不变形<br>- 扫光与小四角星在元素本身设有 `opacity="0"`，当代码关闭全部动画生成桌面静止版时，外观与上一批静态稿 100% 一致 |
| `gem_red_shine` | `100×100` | `2.6s` 循环：外圈淡光（`#halo`）缓慢一呼一吸，周围三颗四角星（`#star_1`、`#star_2`、`#star_3`）错峰轮流闪烁 | 无（纯待机 `img`） | - 在上一批静态稿原结构上直接驱动外圈光晕与三颗四角星的 `transform` 和 `opacity`<br>- 关闭动画时所有元素恢复默认静止帧，与上一批静态稿完全一致 |
| `ui_heart` | `64×64` | `1.6s` 循环（`steps(8, end)`）：挂坠主体很轻的心跳律动（峰值放大 `5.2%`，不超过 `6%`） | `lose`：`600ms`<br>`gain`：`500ms` | - `lose`：挂坠轻颤，心形红宝石浮现裂纹并压暗（`#dark_overlay`），3 块红宝石碎片往下掉落（`#shards_fall`），最后整体全透明（`opacity: 0`）<br>- `gain`：从 `0.22` 倍小尺寸弹出至 `1.1` 倍再回落，同时宝石表面与四角星闪一下（`#gain_flash`） |

## 2. 使用的配色与 `style.config.mjs` 之外的颜色说明

除宝石本体与宝石受光/反光特效外，所有木质、铁箍、旧铜、眼白、排线、阴影、裂变暗面均严格取自 `style.config.mjs`：
- **墨线与阴影**：`ink` (`#1C1412`)、`white` (`#E6DEC8`)、`shadow` (`#0D111C`)
- **旧木与羊皮纸**：`ochre.d` (`#704122`)、`ochre.deep` (`#3D2212`)、`parchment.c` (`#C8B894`)、`parchment.d` (`#9A8968`)、`parchment.l` (`#E2D6BA`)
- **灰铁与冷轮廓光**：`slate.c` (`#5A7682`)、`slate.d` (`#3B515C`)、`slate.l` (`#8CAAB5`)、`slate.deep` (`#1E2C33`)
- **旧古铜**：`brass.c` (`#9A7B46`)、`brass.d` (`#6E542B`)、`brass.l` (`#C2A670`)、`brass.deep` (`#3B2B14`)
- **暗酒红与暗夜紫**：`wine.c` (`#8C3B45`)、`wine.d` (`#5E242C`)、`wine.l` (`#B5626C`)、`plum.deep` (`#161221`)
- **死灰裂变**：`gray.l` (`#948F86`)、`gray.deep` (`#2E2C28`)

**`style.config.mjs` 之外的高饱和宝石色（沿用上一批现有宝石素材色板与 `素材清单.json` 的 `palette.gem`）：**
- **红宝石色系**（用于 `gem_red_cut`、`gem_red_shine`、`ui_heart` 心形红宝石、`card_art_hammer` 锤头圆宝石、`mon_chest` 锁扣红宝石及 `gems_spill` 红宝石）：
  - 主色 `#E3263A`、亮面 `#FF5C6E`、浅粉高光 `#FFD6DC` / `#FFF0F2`、暗部刻面 `#9E1424` / `#5C0A14`、镜面高光点 `#FFFFFF`
- **绿宝石色系**（用于 `mon_chest` 的 `gems_spill` 绿方宝石，与 `gem_icon_green.svg` 一致）：
  - 主色 `#1DBF5E`、暗部刻面 `#117A3B`、高光点 `#FFFFFF`
- **蓝宝石色系**（用于 `mon_chest` 的 `gems_spill` 蓝三角宝石，与 `gem_icon_blue.svg` 一致）：
  - 主色 `#2E66F0`、暗部刻面 `#193D9E`、高光点 `#FFFFFF`

## 3. 设计取舍与自查说明

1. **`mon_chest` 从 `daze` 切换到 `hit` 的衔接**：
   - 将宝箱怪的基础几何姿态设为“箱盖半张、露出尖牙与箱缝小眼”，因此无论是从 `idle` 还是从 `daze`（半开嘴发晕）切入 `hit`（后仰缩身 `6.5°` 再弹回），箱盖与箱体都不会发生生硬跳变。
   - `daze` 的眩晕小星与蚊香眼全部采用浅羊皮纸色（`#E2D6BA` / `#C8B894`）和冷灰青（`#8CAAB5`），不加发光滤镜或暖黄光晕，严格遵守“浅色不发光、不要琥珀暖光”。
2. **`card_art_hammer` 的构图避让**：
   - 战锤采用右下握柄、左上锤头的斜置构图，锤头主体控制在 `x: 42..150, y: 34..108`，打出时的冲击线控制在 `x: 33..94, y: 94..156`，确保左上角 `x: 0..30, y: 0..90` 在待机和打出全过程中完全留空，叠加卡牌左上角宝石小图标时绝不遮挡。
3. **画框边界与性能控制**：
   - 全部 5 个素材的所有动画（含 `mon_chest` 的 `attack` 扑咬放大、`hit_big` 飞木片、`die` 散架吐宝石，以及 `ui_heart` 的 `lose` 掉碎片、`gain` 弹出）均严格控制在各自 `viewBox` 边界与安全留白内，`预览.html` 逐帧出框检查全部 0 报警。
   - 动画仅操作 `transform` 与 `opacity`，无滤镜/渐变/路径变形动画；小素材每个仅驱动 2–4 个轻量节点，保证同屏数十个素材流畅运行。
