# 新卡牌 第一版 Demo · 美术素材交付说明 (`notes.md`)

## 1. 交付概览

本次一次性交付 `素材清单.json` 定义的**全部 34 个标准素材**（第一批 18 个 + 第二批 16 个），外加第二批二选一造型的 **3 个备选皮肤素材**（放于 `out/skins/`，方便后续作为皮肤切换使用）：

- `out/<id>.svg`：34 个标准 SVG 矢量素材（根元素均含 `class="svg-<id>"`、`viewBox` 与等值 `width`/`height`、`<g id="root">`，透明底）。
- `out/<id>.png`：34 个对应的 **2 倍分辨率**透明底 PNG（静态与待机素材为静止态，6 个 `fx_*` 特效素材导出最亮峰值帧）。
- `out/skins/<id>_*.svg` 及 `.png`：3 套第二批备选皮肤变体（详见第 4 节）。
- `src/`：完整可复现的生成脚本 `generate_assets.mjs` 与 2× PNG 渲染脚本 `render_pngs.mjs`。

## 5. 设计取舍与细节核对

1. **色弱友好与小尺寸辨识度**：
   - 红（圆）、绿（方）、蓝（尖朝上三角）各自锁定外轮廓顶点：同一颜色的 `rough`、`cut`、`shine` 三种形态外轮廓完全一致，升级切换时绝不跳位；转为黑白或缩至 56px / 74px 时依然能一眼区分形状与等级。
   - `rough` 控制在约 35%–40% 的晶石裸露面积，无星芒高光；`cut` 刻面分明并带单点高光；`shine` 叠加内部透光渐变、外围淡光晕与 3 颗哥特四角星闪（纯静态无动画，保障同屏几十颗时的性能）。
2. **卡牌层叠与挖空精度**：
   - `card_frame` 使用 `fill-rule="evenodd"` 将原画窗（`x=14..186, y=14..198, rx=6`）挖成真正的全透明孔洞，旧铜窗框向内压边 2px（对应 `cardLayout.artWindow` 的 `x12 y12 w176 h188 r8`），下半截文字框（`y=222..290`）保持深暗平整。
   - `card_art_bg` 左上角 `x=0..34, y=0..94` 特意留平，避免干扰左上角叠放的 `gem_icon`。
   - `card_gem_bar` 的圆槽 `(30,17)`、方槽 `(66,17)`、三角槽 `(102,17)` 均做成深色内凹坑加底部受光边，空置时一眼可辨。
3. **九宫格拉伸安全区**：
   - `table_cloth`（切线 72）、`ui_panel`（切线 48）、`ui_btn` 与 `ui_btn_primary`（切线 32）的所有铆钉、包铜角花均严格收在四角切线以内，四条拉伸边仅保留平行于拉伸方向的直线边框，中间区域纯平，任意横竖拉伸均不变形。
