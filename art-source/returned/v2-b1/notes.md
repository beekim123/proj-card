# 新卡牌 第二版 · 美术 第 1 批（样稿）制作说明（`notes.md`）

## 1. 总体修改与硬性规则落实情况

1. **同一动作所有部件严格共享同一组关键时间点**：每个动作（含 `idle` 待机及 `daze` 进场/循环）的所有运动部件均使用完全相同的 `@keyframes` 百分比节点与分段缓动函数，各部件开始变化、到位停顿与回弹的时刻 100% 重合（不重合次数为 0）。
2. **全面移除 `steps()` 与线条沸腾**：3 个 SVG 中均不再使用 `steps()`，并移除了第一版的 `.boil-a` / `.boil-b` 双层沸腾描边；顿挫感全部通过“快速到位（`cubic-bezier(.2,.8,.2,1)`）→ 原位停住保持（`linear` 零位移段）→ 弹回过头（`cubic-bezier(.34,1.56,.64,1)`）/ 平滑归位（`ease-in-out`）”实现。
3. **会动的组不挂滤镜、只动 `transform` 与 `opacity`**：移除了原 `#box` 上的 `<filter>`，所有 `@keyframes` 仅修改 `transform` 与 `opacity` 属性。
4. **缓动函数严格限定**：全包仅使用规范指定的 4 种缓动函数：
   - 到位：`cubic-bezier(.2,.8,.2,1)`
   - 呼吸、晃：`ease-in-out`
   - 弹回带过头：`cubic-bezier(.34,1.56,.64,1)`
   - 淡入淡出 / 停顿保持 / 匀速旋转：`linear`
5. **逐帧不出框检查**：按 20ms 一帧逐帧扫描全部事件与待机循环，所有部件顶点与路径均严格处于各自 `viewBox` 画框之内（0 处出框）；`card_art_bag` 与 `card_art_stone` 左上角 `x: 0–30, y: 0–90` 区域全程留空。

## 3. 有无做不到的地方

**全部需求均已完整实现，无做不到的地方。**
唯一需要说明的细节是：`mon_chest` 待机要求“周期 2400ms（0 低 → 1200 高 → 2400 低），眼睛每两轮眨一次，眨眼也落在 1200”。为了既满足“身体 2400ms 一呼一吸、眼睛每两轮在 1200ms 处眨一次”，又严格保证所有部件的 CSS `@keyframes` 周期与百分比节点完全一致，我们将 `idle` 设为 `4.8s`（即两轮 `2400ms` 合一，`0% / 25%(1200ms) / 50%(2400ms) / 75%(3600ms) / 100%(4800ms)`）：箱体、箱盖、舌头、牙齿、阴影在 `0%→25%→50%` 与 `50%→75%→100%` 执行两次完全相同的 `2400ms` 呼吸，而眼睛在第一轮 `1200ms (25%)` 处眨眼闭合、第二轮 `3600ms (75%)` 处正常睁眼随呼吸上浮，从而实现视觉周期与关键时间点的 100% 同步。
