# 新卡牌 第二版 · 美术 第 2 批制作说明（`notes.md`）

## 1. 总体规范与精灵图新规落实情况

1. **同一动作所有部件严格共享同一组关键时间点**：每个动作（含 `idle` 待机及 `daze`、`wound_down`、`light` 等事件）的所有运动部件均使用完全一致的 `@keyframes` 百分比节点与分段缓动函数，各部件开始变化、到位停顿与回弹的时刻 100% 重合（不重合次数为 0）。
2. **全面移除 `steps()`、线条沸腾与运动组滤镜**：全部 16 个 SVG 均不使用 `steps()`、`transition`、`<animate>`、`<text>`、脚本或外部引用；四只怪已彻底移除旧版的 `.boil-a` / `.boil-b` 沸腾描边及 `#legs`、`#body`、`#case`、`#pile` 上的 `<filter>`，所有 `@keyframes` 仅修改 `transform` 与 `opacity`。
3. **缓动函数严格限定为 4 种**：
   - 到位：`cubic-bezier(.2,.8,.2,1)`
   - 呼吸、晃：`ease-in-out`
   - 弹回带过头：`cubic-bezier(.34,1.56,.64,1)`
   - 淡入淡出 / 停顿保持 / 匀速旋转：`linear`
4. **第 0 帧即静止姿势、首尾帧严丝合缝**：
   - 所有动画关掉时的静止姿势 = 待机第 0 帧 = 每个事件的第 0 帧；
   - 所有非 `stay` 事件（`die` 与 `out` 除外）播完最后一帧（`100%`）均严格回到静止姿势；
   - 待机循环统一为 `3000ms`（`3s`），眨眼/歪头动作直接落在单轮循环的 `1500ms (50%)` 处，首尾帧 100% 一致。
5. **文字槽、图标槽与 `currentColor` 染色**：
   - `mon_clock.svg` 的 `<g id="countdown_slot"></g>` 为空 `<g>`，置于 `#dial` 内随表盘同步运动；表盘中心 `(160, 140)`、半径 `56` 区域保持浅色平整留空，不画数字。
   - `ui_rule_sign.svg` 的 `<g id="icon_slot"></g>` 与 `<g id="rule_text"></g>` 均为空 `<g>`，置于 `#board` 内随木板同步摆动与翻转；`x: 84–264` 写字区平整浅色，不画字、不压钉子。
   - `ui_rainbow_slot.svg` 仅在槽内发光宝石 `#gem_lit` 与外圈光环 `.slot-glow` 上使用 `currentColor` 做纯色填充与描边，铜边与暗底空槽不使用 `currentColor`。
6. **逐帧不出框检查**：按 20ms 一帧逐帧扫描全部素材的待机循环与所有事件，0 处出框。
