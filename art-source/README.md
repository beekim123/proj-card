# 美术源文件（art-source）

## 当前运行版本：2026-11-11 新画法全量接入

当前原生游戏使用 `art/svg/` 的118份新画法SVG及其逐帧导出的 `art/sprites/`，完整清单为 `art/art-manifest.json` v5。来源为设计画风库Fable/Carbon和03–07包，逐ID来源及SHA-256记在 `art/new-art-provenance.json`。本目录下旧交付属于历史记录，不参与当前原生打包。

接收更新：`node tools/receive-new-art.mjs /绝对路径/design`；随后依次运行 `npm run export:sprites`、`npm run import:sprites`、`node tools/check-new-art.mjs`、`bash tools/import.sh`、`bash tools/check.sh`。事件30fps、循环15fps，单worker顺序运行；禁止用旧占位图补齐缺稿。技术检查和用户视觉验收分开记录。

以下为旧美术的历史交接，路径和数量不代表当前运行版本。

这个游戏的美术存档和参考，从设计目录的画风库（`design/style-lab/`）同步过来，2026-11-10。

- **游戏实际用的是 `public/art/`**（SVG + `public/art-manifest.json`，素材清单第 4 版，89 个）。这里不参与打包。
- 以后每批美术交回，都在 `returned/` 加一份，并在本文件的表里加一行。

## 美术是怎么做的

- 外包画手（AI）用代码画 SVG，每个素材一个文件。动画写在 SVG 自己的 CSS 里：
  - 代码设 `data-anim="hit"` 这类事件，播一次；
  - 没有事件时播待机。
- **SVG 是源文件。** 游戏里用逐帧导出的 **PNG 精灵图**（2026-11-10 起，见下面“精灵图”一节），以后进 Godot 也用这套。
- 每个素材的 id、尺寸、事件、部件、落地点、打击点都写在素材清单里：
  - 第一版是 `public/art-manifest.json`；
  - 第二版是 `v2/素材清单-v3.json`。
- 画风是"哥特"（参考第五人格那一类的气质）：
  - 焦茶近黑的手绘钢笔线；
  - 低饱和配色；
  - **只有宝石是鲜艳、发光的**（红圆、绿方、蓝三角）；
  - 不要琥珀暖光、不要火光；
  - 怪是"古堡里活过来的旧东西"，诡萌，不吓人。
  
  细则在 `style-gothic/README.md` 和 `style-gothic/style.config.mjs`。

## 已知问题（第二版要改的）

- **动起来"卡"**：评估逐格量过，不是掉帧。原因有两个：
  - 待机里每个部件各自用 `steps()` 分格、互不同步，加上线条沸腾，看起来像在抖；
  - 受击、出手幅度小、节奏匀，没有"一下到位再弹回"。
- 第二版的新动法写在 `v2/第1批-美术需求.md` 第 2 节：同一个动作所有部件同一组时间点换姿势，用"停住"代替逐格，待机顺滑呼吸。先拿宝箱怪做样稿，过了再改另外四只怪。
- 口袋、磨石的原画看不出效果，第二版重画。

## 精灵图

2026-11-10 定：游戏里的美术换成 PNG 精灵图，从第二版第 2 批开始。画手照旧交 SVG（源文件），我们逐帧导出。规范在设计目录 `新卡牌/精灵图规范.md`。

- 美术换了：把 SVG 放进 `public/art/`，跑 `npm run export:sprites`（全部）或 `npm run export:sprites <id> …`（几个），结果在 `public/sprites/`。
- 忘了重导：`npm test` 里的 `src/art/sprites.test.ts` 会报“过期”；游戏里这个素材自动退回 SVG。
- 对照原 SVG：`?art=svg`，或素材检查页 `?page=art`。
