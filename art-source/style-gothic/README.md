# 风格包：哥特

一句话：维多利亚暗黑童话风的手工定格木偶——深褐近黑的锋利抖动钢笔线、收细拉尖微歪的不对称造型、纽扣与缝线诡萌眼、旧纸刮痕与交叉排线暗面，在冷灰青轮廓光与一处摇曳琥珀暖光里一顿一顿地活过来。

示例：[examples/monster_froglet.svg](examples/monster_froglet.svg)。

## 1 画法要点

| 项 | 规则 |
|---|---|
| 线 | 全用焦茶近黑手绘线 `ink`（`#1C1412`，**严禁纯黑 `#000`**）。起收笔削尖、略带神经质手抖与断笔；外轮廓粗（2.6–3.8px），内部分结构与缝线细（1.0–1.8px）。关键轮廓叠一套微偏的次级沸腾描边（`.boil-a` / `.boil-b`） |
| 形 | 在原角色剪影基础上**收细、拉尖、带一点歪**：眼包一大一小略偏、耳尖与尾尖拉出锋利折角、帽筒与烛身带不对称折痕，但核心识别特征（蛙仔圆肚与双眼包、狐火大尾与尾尖火、镜灵手镜与大独眼、蜡烛烛泪、魔术帽高筒与星光）完整保留 |
| 眼睛 | 诡异又可爱的“诡萌”眼，不同角色各异：**蛙仔**用四孔深色旧纽扣眼 + 暗酒红十字缝线 + 针尖亮瞳；**狐火**用深陷黑眼圈 + 琥珀发光细竖瞳 + 眼角缝线；**镜灵**用深渊眼窝 + 同心裂纹骨瓷白 + 极小针尖亮瞳 |
| 质感 | 矢量交叉排线（45°/135° 钢笔细密排线）压在背光侧与底部；干笔刷暗面色块与少量手工布偶缝线、补丁针脚；外层套轻量旧纸颗粒与微颤滤镜（`gothic-grunge`），保证 74px 小图干净清晰、放大有手工做旧肌理 |
| 光 | **冷色环境 + 一处琥珀暖光**：整体压暗偏冷；剪影左上/外侧边缘勾一道细锐的冷色轮廓光（`moss.l` / `slate.l` / `plum.l` / `parchment.l`），确保在深色底（`#1B2440`）上轮廓分明；每个角色集中一处琥珀暖光（烛火、鬼火、竖瞳、共鸣芯或纽扣反光） |
| 杂音斑 | 怪物的 `static_patch` 画成**旧胶片竖向刮痕、断续细线与闪烁噪点斑**（`noise` `#D8CEB8` + `ink` 深痕），待机时跳帧闪烁，受伤时放大加密 |

## 2 配色

只改 [style.config.mjs](style.config.mjs)。

- 每个色族分四档：`c` 主底色，`d` 背光暗面与次级部件，`l` 冷/暖受光边与高光，`deep` 最深衬底与凹槽（均带色彩倾向，不用纯黑）。
- **单角色用色上限**：每个角色最多使用 **2 个主色族 + 1 个点缀色族**（外加通用 `ink`、`white`、`noise`、`shadow` 及裂变状态专用的 `gray`）：
  - **蛙仔**：`moss`（旧苔绿）+ `parchment`（旧羊皮纸）+ 点缀 `wine`（暗酒红腮红与纽扣十字缝线）
  - **狐火**：`ochre`（旧褐狐毛）+ `parchment`（胸腹浅毛）+ 点缀 `amber`（琥珀尾尖鬼火与竖瞳）
  - **镜灵**：`brass`（旧古铜镜框）+ `slate`（灰青冷镜面）+ 点缀 `wine`（暗酒红宝石与腮红）
  - **蜡烛**：`parchment`（旧蜡身与烛泪）+ `brass`（古铜烛台）+ 点缀 `amber`（琥珀烛火与共鸣芯）
  - **魔术帽**：`plum`（暗夜紫高筒帽）+ `wine`（暗酒红丝绒帽带）+ 点缀 `amber`（琥珀星芒与共鸣芯）
- 落地影统一使用 `shadow`（`#0D111C`），由半透明暗影垫底叠加密集的斜向钢笔排线构成。

## 4 能动的结构与哥特动法

- **严格对齐部件 ID 与层级**：所有 `<g id>` 与参考原图完全一致，`body` 作为核心父层承载呼吸与挤压，长在身上的四肢、五官、尾巴、帽带等作为子层跟随运动。
- **关节只转不移**：四肢、尾巴、耳朵、镜柄装饰等围绕 `<!-- pivot: x,y -->` 旋转（待机 ±1–3°，事件 ±4–14°），根部深入身体层内部 6–10px，旋转绝不露缝；排线与缝线画在所属部件组内，随部件同步运动不漂移。
- **四重哥特动法**：
  1. **定格木偶顿挫感**：待机与事件关键帧结合 `steps()` 或非对称停顿帧，模拟手工定格动画被丝线牵引的微晃与顿挫。
  2. **线条轻微沸腾**：双层微差描边（`.boil-a` / `.boil-b`）以 `steps(2, end)` 低频交替（约 0.36s–0.44s），让手绘墨线在静止中保持呼吸活感。
  3. **不规则暖光摇曳**：烛火、狐火、共鸣芯与眼瞳高光采用多段非均匀关键帧（如 `0% / 18% / 37% / 63% / 82% / 100%`）忽明忽暗、忽高忽低，打破机械匀速呼吸。
  4. **旧胶片划痕闪烁**：`static_patch` 采用 `steps(2, end)` / `steps(3, end)` 跳帧闪动，在 `hurt` 时瞬间张裂放大。

## 5 自查

- [x] **事件与循环**：所有角色事件按钮均可独立触发且时长 ≤ 0.8s，播完平滑回到 `idle`；待机循环首尾相接无跳帧。
- [x] **不出画框**：除 `collect`、`scare` 离场动画外，静止帧与所有事件峰值帧（含 `select` 浮起、`dodge` 跳起、`hurt` 抖动、`crack` 火花）全部严格在 `viewBox` 内。
- [x] **74 像素可读性**：缩至 74×74 像素时剪影特征、纽扣/竖瞳/独眼、冷暖对比依然清晰，排线与缝线不糊团。
- [x] **深浅底兼容**：外侧冷轮廓光保证在 `#1B2440` 深色底上边界清晰，焦茶粗描边保证在 `#F3E6C4` 浅色底上稳重醒目。
- [x] **用色与禁忌合规**：100% 取自 `style.config.mjs`，无 `#000` 纯黑块，无血腥、骷髅、十字架、蝙蝠或外部引用，单文件远小于 300 KB。
