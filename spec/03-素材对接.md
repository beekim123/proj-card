# 素材对接

美术交的是 SVG，一个素材一个文件，文件名就是 `素材清单.json` 里的 `id`。美术没交之前，代码用占位图把整个游戏跑通；美术交了，文件放进 `art/` 刷新就换掉，**不改代码**。

## 1 读素材

1. 启动时读 `art-manifest.json`（就是 `素材清单.json`）。
2. 对每个素材试着读 `art/<id>.svg`：读到就用美术的，读不到（404）就用占位图。全部读完再显示游戏，期间显示"加载中"。
3. 记下每个素材是美术的还是占位的（素材检查页要显示）。

## 2 两种显示方式

看清单里的 `load`：

| load | 怎么显示 | 哪些 |
|---|---|---|
| `img` | `<img src>`。占位图生成 SVG 字符串，转成 Blob URL 当 src | 牌框、宝石、图标、桌布、背景、按钮底……都是静态的 |
| `inline` | 把 SVG 文本塞进页面，变成真正的 `<svg>` 元素 | 有事件的（`dummy`、`ui_mult_badge`）和特效 `fx_*` |

**塞进页面的 SVG，每个实例都要改 id**（同一个素材可能同时出现好几个，id 重复会让渐变、滤镜串掉）：
- 生成一个实例前缀，比如 `i37`。
- 所有带 `id` 的元素：`id="x"` → `id="i37-x"`。
- 所有属性里的 `url(#x)` → `url(#i37-x)`，`href="#x"` / `xlink:href="#x"` → `#i37-x`。
- `<style>` 里的 `#x`（只换这个 SVG 里真有的 id，后面不能紧跟字母、数字、`-`、`_`）→ `#i37-x`。
- class 名和 `@keyframes` 名不改（美术那边已经按 `svg-<名字>` 加了前缀，同一个素材的多个实例用同一套没问题）。

## 3 播事件

美术的 SVG 按这个约定做（和我们画风库的动画 SVG 一样）：
- 根元素 `<svg class="svg-<名字>">`，没有 `data-anim` 时播待机循环。
- `data-anim="hit"` 时播 hit，一次，时长看清单的 `events`。

代码播事件：
```
el.removeAttribute('data-anim')
void el.getBoundingClientRect()   // 强制重排，同一个事件能连着重播
el.setAttribute('data-anim', name)
定时 events[name] 毫秒后，如果 data-anim 还是 name，就去掉它（回到待机）
```

特效 `fx_*`：没有 `data-anim` 时是全透明的。每次新建一个实例，放到位置上，播 `play`，播完删掉元素。

## 4 染色

清单里 `tint: true` 的特效，美术用 `currentColor` 画会变色的部分。代码在这个 `<svg>` 上设 `style.color`：
- 牌的混色：`palette.mix[宝石位]`
- 空托（没有混色）：`palette.text`
- `fx_grow` 用长了的那颗宝石的颜色 `palette.gem.<色>.mid`

## 5 九宫格

清单里有 `nineSlice: [上, 右, 下, 左]` 的素材（桌布、底板、按钮）用 CSS `border-image`：
```
border-style: solid;
border-image-source: url(素材);
border-image-slice: 上 右 下 左 fill;
border-image-width: N;   /* 显示的边宽，见 02，比如桌布 72、顶栏 24 */
```
美术的 SVG 根上会写 `width` / `height`（等于 viewBox 大小），切线数字就按这个算。

## 6 对齐点

清单里有 `anchor` 的（木桩、兵器架）：素材里的这个点对到布局表给的点上。显示大小就是 viewBox 大小（1 倍）。

## 7 拼一张牌

坐标全在清单的 `cardLayout` 里（牌面单位 200×300），图见 `参考/卡面结构.svg`。

- 牌是一个 200×300 的容器，所有层按牌面坐标摆，整张用 `transform: scale()` 缩成 0.75 / 1.4 / 2 倍。
- 从下往上叠：
  1. `card_art_bg`：铺满原画窗 `artWindow`。
  2. 混色光：原画窗里一个径向渐变，中心 `glow.cx/cy`，半径 `glow.r`，颜色 `palette.mix[宝石位]`，透明度 `glow.opacity`。空托没有。
  3. 宝石：按宝石数量取 `cardLayout.gems` 的位置和边长，每颗用 `gem_<色>_<rough|cut|shine>`（看这颗宝石**现在**的形态）。空托用 `card_art_empty` 铺满原画窗。
  4. `card_frame`：整张，原画窗那块是透明的。
  5. `card_gem_bar`：在 `gemBar` 的位置。
  6. 宝石栏里：有的宝石在对应 socket 上放 `gem_icon_<色>`（24×24，中心对齐 socket）。
  7. 左上角：有的宝石放 `gem_icon_<色>` 在 `corner` 的固定格，没有的空着。
  8. 文字：建议用一个盖满整张牌的 200×300 `<svg>` 写 `<text>`，基线、字号、颜色照 `cardLayout.text`。底数组成那行太长：先换紧凑写法 `红150+绿100+蓝200`，还长就缩字号，最小 16。
- 宝石长了一级时，所有牌上这颗宝石的图都要换。

## 8 素材检查页

网址加 `?page=art` 打开。给我们对美术用的：
- 按清单的 `group` 分组，一格一个素材：显示素材（按 1 倍）、id、viewBox、**美术 / 占位**。
- 有事件的：每个事件一个按钮，点了播。
- 九宫格素材：同时显示三种拉伸大小（比如桌布 1032×330、1248×330、300×300）。
- 8 种牌各拼一张；上面一个切换：三颗宝石都原石 / 都切好 / 都闪光 / 红切好绿原石蓝闪光。三种显示倍数（0.75 / 1.4 / 2）都摆出来。
- 页面底色可以切深色 / 浅色。

## 9 占位图

美术没到之前，占位图要**和真素材一样大、一样的约定**（同样的 viewBox、同样的事件、同样的 `currentColor`），这样换成美术时不用改代码，也能提前把塞进页面、改 id、播事件这些都测好。颜色只用 `palette` 里的。

| 素材 | 占位 |
|---|---|
| 通用 | 填 `panelBg` 的圆角矩形，`textDim` 虚线边，中间写 id |
| `gem_*` | 按颜色画形状：红圆、绿方、蓝三角，占 viewBox 80%，`ink` 描边。原石：灰褐色（`#4a4440`）形状上一块 45% 透明的宝石色；切好：实心宝石色；闪光：实心 + 两颗白色四角星 |
| `gem_icon_*` | 同形状实心，粗描边 |
| `card_frame` | 深色圆角牌身，原画窗挖空（evenodd），窗边和外边一圈 `accent` 细线 |
| `card_art_bg` | `panelBg` 实心 |
| `card_art_empty` | 一个空的圆环托 + 三个小爪，`textDim` 色 |
| `card_gem_bar` | `accentDark` 圆角条，三个槽（圆、方、三角）填 `ink` |
| `dummy` | 褐色木桩 + 圆脑袋 + 胸口两圈靶子；`hit`：整个绕底边中点往后歪 6° 再回来；`hit_big`：歪 14°，脑袋换成两个圆圈吃惊眼（`face_hurt`）|
| `ui_mult_badge` | `accentDark` 圆角矩形；`up`：一道白光扫过；`double`：四周几个点散开 |
| `fx_*` | `currentColor` 圆圈从 0.3 倍放大到 1.2 倍并淡出（`fx_shun` 是竖条从下往上，`fx_rainbow` 是六色弧，`fx_white` 用白色）|
| 九宫格素材 | 圆角矩形加边框，四角画个小方块，能看出拉伸对不对 |
| `ui_icon_*` | 写一个字：规则 `?`，设置 `≡`，撤回 `↶`，牌库 `▤` |
| `bg_tile` | `pageBg` 实心 |
