# 界面布局

数字都是**设计尺寸**的像素：竖屏 1080×1920，横屏 1920×1080。舞台按设计尺寸摆好，再整体等比缩放到屏幕。线框图：`参考/竖屏布局.svg`、`参考/横屏布局.svg`（以本文的数字为准）。

**两种布局用同一套素材，素材显示的大小也一样，只换位置。** 所以组件不能写死坐标，全从布局表取。

## 1 舞台和缩放

- 舞台 = 一个设计尺寸大小的容器，`scale = min(可用宽 / 设计宽, 可用高 / 设计高)`，居中。可用区域要扣掉手机安全区（`env(safe-area-inset-*)`）。
- 舞台外面：整个页面铺 `bg_tile`（平铺，瓦片大小跟着 scale 缩），再盖一层四周压暗的径向渐变。页面底色 `palette.pageBg`。
- **用哪种布局**：网址带 `?layout=portrait` 或 `?layout=landscape` 就用它；否则看设置；设置是"自动"时，屏幕宽 > 高用横屏，不然用竖屏。屏幕转了要马上换。第 2 步只做竖屏，第 3 步加横屏。
- 字最小 28（缩放到 390 宽的手机上大约 10px）。牌上的字跟着牌缩放，不受这条限制。

## 4 桌面排怎么摆

牌宽 W = 150。每张牌的左边 = 上一张的左边 + 间距，间距看这张的反应：

| 反应 | 间距 | 意思 |
|---|---|---|
| 本回合第一张 | 从起点开始 | |
| 同色 | 0.6W = 90 | 叠住 40% |
| 顺色 | W + 4 = 154 | 挨紧 |
| 凑白 | W + 4 = 154 | 挨紧，接缝处白光（`fx_white`） |
| 普通 | W + 30 = 180 | 留一道缝 |

- 后出的牌压在上面。
- **放不下**（最后一张右边超过右边界）：从最早的间距开始压，每个最小压到 56（露出左上角的宝石标），最新的 3 个间距尽量不压。全压到 56 还放不下，就所有间距平均分。压缩时用 200ms 过渡。
- **反应标签**：一个小牌子（底 `#E2D6BA`，字 `ink` 22 号，高 32，圆角），中心在这张牌的左边缘上。间距小于 100 的接缝不显示标签（最新那张除外）。
- **每张伤害**：写在牌下中间。间距小于 100 的不显示（最新那张除外）。
- **彩虹**：顺色链里的牌往上拱成弧，第 j 张（链里从 0 数，共 n 张）上移 `round(sin(π × (j + 0.5) / n) × 48)`，400ms 缓出。弧上方中间播 `fx_rainbow`。
- 回合结束：桌上的牌依次往牌库按钮方向滑走、变淡（250ms，每张间隔 30ms）。

## 5 手牌

- 扇形：n 张，第 i 张（从 0 数），mid = (n − 1) / 2，d = i − mid。
  - 间距 `step = min(160, (可用宽 − 280) / (n − 1))`（竖屏 6 张 = 150，8 张 = 107）
  - 牌中心 x = 中心 x + d × step
  - 牌顶 y = 基准牌顶 + d² × 6
  - 绕牌底边中点转 d × 4°
  - 右边的牌压在左边的上面
- **按下**一张牌：马上抬高 80、放大 1.1、不转（100ms）。
- **拖**：按下后移动超过 12 再开始拖。
  - 牌跟着手指走。触屏时牌中心在手指上方 200（别被手指挡住）；鼠标时保持按下的位置。
  - 其余手牌合拢重排（150ms）。
  - 手指不在手牌区、也不在按钮上 → 显示**落点预览**：桌面排下一个位置上一张半透明（0.5）的牌，按反应摆，带反应标签和预计伤害（提示关着时只有位置）；算式行显示预计算式。
  - **松手**时手指不在手牌区、也不在按钮上 → 打出；否则牌飞回原位（200ms）。
- **点一下**（没拖）：放大看牌，2 倍（400×600）显示在屏幕中间，后面压暗 60%，再点任何地方关。
- **提示**：能起反应的手牌外圈发光（accent 色，24 模糊），牌顶上方 40 处一个反应标签。
- 补牌：新牌从牌库按钮飞到手牌位置（220ms，每张间隔 60ms）。

## 6 出一张牌的表现顺序

规则在松手那一刻就算完；下面只是表现。**任何时候都不锁输入**，上一张的动画没播完也能拖下一张，表现可以叠在一起。

| 时间 | 发生什么 |
|---|---|
| 0 | 牌从松手的位置飞到桌面排的位置（180ms，缓出） |
| 180ms | 落下压扁一下（纵向 0.92 → 1，120ms）；反应标签弹出；接缝处播反应特效（同色 `fx_same` / 顺色 `fx_shun` / 凑白 `fx_white`，染这张牌的混色）|
| 180ms | 木桩：伤害（含彩虹加成）≥ 20,000 或者凑白 → `hit_big`，否则 `hit`；木桩上随机一点播 `fx_hit`；飘字 |
| 180ms | 倍率牌：+1 播 `up`，翻倍播 `double`；整块（牌子 + 字）弹一下（1 → 1.15 → 1，200ms）；数字换新 |
| 180ms | 本回合数字从旧值滚到新值（300ms）；顶栏的最高、累计跟着变 |
| 380ms | 触发彩虹：链拱成弧，`fx_rainbow`，彩虹加成单独飘字，提示条"彩虹！这回合 ×10" |
| 580ms | 宝石长了一级：那条成长条上播 `fx_grow`，提示条"红宝石变成切好，底数 100 → 150"；所有显示这颗宝石的牌换成新形态 |

**飘字**：`-3,200`，72 号粗，`text` 色加 3px `ink` 描边；≥ 1 万用 88 号、accent 色。出现时 1.3 → 1（120ms），900ms 内往上飘 120，最后 300ms 淡出。彩虹加成飘字 `彩虹 +18.81万`，96 号，文字填六色渐变（`palette.mix` 的红黄绿青蓝品红）。

**提示条**：竖屏在 (540, 340)，横屏在 (324, 120)，排队一条一条出，每条 1200ms。底 `ui_panel` 边宽 24，字 30。

## 7 弹窗

都是屏幕中间的 `ui_panel`（边宽 48），后面压暗 60%，右上角关闭，点外面也关。竖屏宽 920，横屏宽 1000。

**规则**（文案照抄）：
- 宝石：红是圆的，绿是方的，蓝是三角的。（三个小图标）
- 把手牌拖到桌上就打出去，接在这一排最右边。
- 伤害 = 宝石底数 × 倍率 × 反应。倍率从 ×1 开始，每出一张 +1。
- 和上一张比宝石：一样 → 同色 ×2；差一颗 → 顺色 ×2，倍率翻倍；三颗全不一样 → 凑白 ×5，倍率翻倍；差两颗 → 没反应。
- 彩虹：顺色一路连出红、黄、绿、青、蓝、品红六种颜色，这回合 ×10，每回合一次。
- 宝石越用越值钱：用 15 次变"切好"，底数 150；用 45 次变"闪光"，底数 200。
- 结束回合：桌上的牌收走，倍率回到 ×1，手牌补满。

**设置**（存 localStorage，key `gemcard.settings`）：
- 提示：开 / 关（默认开）
- 手牌：6 / 8（默认 6）
- 布局：自动 / 竖屏 / 横屏（第 3 步加）
- 测试用：成长 开 / 关；成长清零；重新开始（先确认："重新开始会清掉这局的回合、伤害和宝石成长"）

**成长详情**（点成长条）：`红宝石 · 切好 · 底数 150 · 用了 23 次 · 再用 22 次变闪光（底数 200）`；闪光时写"已经是闪光"。

**牌库**（点牌库按钮）：8 种牌各剩几张（左边画这种牌的宝石小图标，右边张数），最后一行 `弃牌堆 7 张`。

## 8 按钮状态

- 按下：压暗 15%，往下沉 4（80ms）。
- 不能点：灰掉（灰度 0.6，透明 0.5）。撤回在本回合没出牌时不能点；结束回合一直能点。
