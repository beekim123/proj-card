## 本批实现

### 规则与局内流程

- `RUN.acts` 为幕数组，本批只有门厅第一幕，六间房依次为小怪、门、精英、门、门、首领；血量为 2 万、4 万、10 万、25 万、45 万、100 万。
- 两扇门使用局内 RNG 确定怪和不同奖励，排除上一次打过的小怪；满心不出回心奖励。选定后不能反选，奖励为额外牌、工坊或回一颗心。
- 工坊支持丢 1–3 张、复制一张、跳过；最少保留 20 张，每种额外牌最多两张，复制使用新身份。
- 开局和精英后必须选宝物；宝物列表按获得顺序保存，精英先回满心、增加手牌上限，再发未拥有宝物选项。
- 沙漏、封条、影子、哨子与四件新宝物接入效果表；锤子改为 ×3，所有摸牌受 12 张硬上限约束。新效果沿用预览、出牌、撤回管线。
- 本批没有实现第二/三幕、收藏室、加码、商店金币或联网等排除项。

### 存档

- 写入版本 4，支持开局/精英宝物选择、战斗、战利品、挑门和工坊各活动阶段。
- 保存幕/间、门与当前奖励、上一只小怪、整副牌、多宝物、RNG、封条、行牌及配对撤回历史。第一张额外牌是否已用由已保存的本回合行牌还原，不另维护易失计数。
- 校验支持工坊后的短牌组、影子/镜子已经变化的行牌宝石位、沙漏超过满值的倒计时和慢一拍后的倒计时上限。
- 版本 0–3 返回“过期”并清除活动局；沿用既有首页更新提示，纪录和设置保持原键与格式。

### 界面与交互

- 新增门和工坊布局配置；门支持选中说明、再次确认、1/2/回车，开门和怪走入反馈。
- 工坊显示整副牌，支持分组、滚动、选择、规则限制、检查卡牌和确认反馈。
- 精英后选择宝物、多宝物栏、9–12 张手牌缩放/横滑、新牌说明、封条、沙漏倒计时、哨子摸牌、双次效果标记。
- 老门环开局循环台词和胜负台词；新增对应 WebAudio 合成反馈。
- debug 增加血量倍数、指定门、工坊、加手牌、封条以及新牌/宝物入口。
- `twice` 二次反馈补充了沙漏 tick/绿闪、锤子冲击、放大镜倍率牌/声音、磨石三颗成长光效；口袋/哨子按实际摸牌列表逐张飞入。延迟、观感和声音仍未在真实浏览器核验。
- 以上为代码实现范围；真实布局、触摸、音色、动画和性能尚未验收。

### 素材

- 已换上第 4 版 89 项素材清单，并生成全部占位素材；其中 14 项为本批新增。
- 89 项完成 XML 结构校验，新增素材的事件/部件契约完成离线校验。

### 机器人对照实测

- 跟提示、乱拿 300 局：生产通关 48.7%，参考 50.3%，差 -1.6 个百分点；每局被打 3.22 次，对照 3.17 次。

## 用户本地安装、启动、复验与打包

建议使用 Node.js 24 LTS；原项目需要兼容 Vite 7 的 Node 20.19+ 或 22.12+。离线验证脚本依赖 Node 24 的接口，推荐统一用 24。

在项目目录执行：

```sh
npm ci
npm test
npm run typecheck
npm run build
npm run dev -- --port 8780
```

开发访问 `http://localhost:8780/`。`?debug=1` 打开调试入口，`?layout=portrait` / `?layout=landscape` 指定方向，`?page=art` 打开素材检查页。macOS 的 `启动.command` 保留，可双击安装依赖、启动并打开页面；若安装仍失败，应先检查本地 npm 网络/代理和 registry 权限，不要跳过错误宣布构建成功。

若先做无依赖规则复查，可在 Node 24 下执行：

```sh
node verification/run-batch-one.mjs
node verification/v4-save-smoke.mjs
```

正式构建成功后，先运行 `npm run preview -- --port 8780` 验收 `dist/`，不要用 `file://` 打开。`vite.config.ts` 保持 `base: './'`。

运行包需保证 zip 内只有一个顶层 `gemcard-demo/`，其下直接是生产 `index.html`，不是嵌套 `dist/index.html`。下面命令只在 `npm run build` 成功后执行：

```sh
mkdir -p release-runtime/gemcard-demo
cp -R dist/. release-runtime/gemcard-demo/
(cd release-runtime && zip -r ../gemcard-demo-runtime.zip gemcard-demo)
```

完整源码另行压缩，排除 `node_modules/`、临时目录和重复运行包。交回源码、运行包、本批验收清单和交接文件；实际浏览器截图、性能截图和录屏完成后再附上，不用历史图片冒充本批证据。
