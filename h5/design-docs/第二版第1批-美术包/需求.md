# 新卡牌 第二版 · 美术 第 1 批（3 个：宝箱怪返修 + 口袋、磨石重画）

第一版的 63 个素材都收下了，谢谢！静态的造型、配色、统一度都好，**画风不变**。

问题出在**动起来**。我们把每个动作的时间轴按 1/120 秒逐格扫过一遍，又在游戏里玩了，结论是：
- **待机在"抖"**：每个部件各自用 `steps()` 分格，各分各的。宝箱怪待机 2.4 秒里画面变了 82 次，间隔 8 到 100 毫秒乱跳，每次只挪 0.3–1.4 像素。加上线条沸腾，眼睛读到的是抖，不是定格动画。
- **受击、出手太软**：受击身体只挪 6–21 像素，没有"一下到位再弹回"；出手只放大 8%。丢一颗心是全局最重的事，画面上却最轻。

所以第二版换一套动法（第 2 节）。**这一批先拿宝箱怪一只做样稿**，过了再铺到另外四只怪上（第 2 批）。口袋、磨石的原画看不出效果，一起重画。

## 1 这批画什么

清单 `素材清单.json` 里 `v2: "第1批"` 的 3 个：

| id | 大小 | 做什么 |
|---|---|---|
| `mon_chest` | 320×400 | **返修**：造型不变，按新动法重做全部动作，加一个新事件 `bite` |
| `card_art_bag` | 176×188 | **重画**：口袋，一眼看出"摸 2 张" |
| `card_art_stone` | 176×188 | **重画**：磨石，一眼看出"磨宝石、让宝石长大" |

## 2 第二版的动法（以后所有会动的素材都照这个）

### 2.1 硬性规则

1. **同一个动作，所有部件在同一组时间点换姿势。** 每个动作有一张"关键时间表"（2.3 节），每个部件的 `@keyframes` 百分比只能从这张表里取。不允许箱盖 12.5% 换姿势、舌头 15% 换姿势这种各动各的。
2. **这一批不用 `steps()`。** 定格的顿挫改成"一下到位、停住、再走"：快速到达关键姿势，**停住**（几十到一百多毫秒），再去下一个。顿挫来自停住，不来自分格。
3. **待机是整只一起顺滑地呼吸**：周期 2–3 秒，主体上下 6–10 像素。去掉线条沸腾（`.boil-a`、`.boil-b` 这类）。
4. **缓动只用这几种**：
   - 到位：`cubic-bezier(.2,.8,.2,1)`（快进慢停）
   - 呼吸、晃：`ease-in-out`
   - 弹回带过头：`cubic-bezier(.34,1.56,.64,1)`
   - 淡入淡出：`linear`
5. **会动的组不挂滤镜。** 做旧纹理、噪点要的话，放在一个单独的、不动的层上。
6. **只动 `transform` 和 `opacity`。**
7. **每一帧都不出画框**，`die` 也不行。整只怪往前扑、被打退的位移和放大**由代码做**（代码会把整只怪放大 1.3 倍扑向镜头），你只做画框里的姿势。
8. 被遮住的部分也要画完整，转动、张嘴时不露缝。

### 2.2 幅度下限

按画框宽 320 算：

| 动作 | 最少要有多大 |
|---|---|
| `hit` | 箱体压扁或拉歪 8% 以上（比如 `scaleY(.92)` 加倾斜 6–10°），换一下眼神 |
| `hit_big` | 15% 以上（`scaleY(.85)` 加倾斜 12–16°），箱盖砰地合上、换 `face_hurt`、木片崩出来 |
| `attack` | 蓄力时整只往下缩 10% 以上；扑出时箱盖张到最大、牙全露、舌头甩出来 |
| `die` | 碎片、宝石飞出至少 100 像素（在框里） |

### 2.3 宝箱怪每个动作的关键时间表

括号里是到这个时间点时的姿势。所有部件都在这些时间点换姿势，中间用 2.1 节的缓动过渡。

| 事件 | 时长 | 关键时间点（毫秒）和姿势 |
|---|---|---|
| 待机 | 2400 循环 | 0（低）→ 1200（高：箱盖抬起 6–10 像素，舌头跟着往上收一点）→ 2400（低）。眼睛每两轮眨一次，眨眼也落在 1200 |
| `hit` | 400 | 0（原样）→ 50（受击到位：压扁 + 往后歪，眼睛闭紧）→ 130（停住）→ 330（弹回，过头一点点）→ 400（回到待机姿势） |
| `hit_big` | 700 | 0 → 60（箱盖砰地合严，牙、舌头、眼睛藏进去，换 `face_hurt`，压扁 15%）→ 200（停住，木片崩到最远）→ 500（弹回带过头，木片落下淡出）→ 700（待机姿势） |
| `attack` | 800 | 0 → 250（蓄力：整只往下缩、箱盖合得只剩一条缝、眼睛眯起）→ 330（扑出：箱盖张到最大、牙全露、舌头甩出来，**这一刻咬中**）→ 450（停住）→ 800（合回待机） |
| `bite` **新** | 300 | 0 → 60（箱盖猛地合上，牙缝里闪一下绿色碎光）→ 140（停住）→ 300（张开回到待机）。比 `attack` 小得多，不扑出 |
| `daze` | 600 进场 + 2000 循环 | 进场 0 → 600：箱盖明显耷拉，只开一条缝；舌头从缝里垂出来挂在箱沿上；整只歪 5–8°；换 `face_daze`，眼睛转圈、头顶一圈小星。循环 0 → 1000 → 2000：慢慢左右晃，小星绕圈 |
| `die` | 1000 | 0 → 150（猛一抖）→ 300（箱盖崩飞起来，两侧木板往外倒，铁箍松脱）→ 600（三四颗宝石从嘴里吐出来，弹落到箱子前面的地上，大约 y 360–390，每颗 22–28 像素）→ 1000（木板和宝石一起淡出，全透明） |

`daze` 挂着时还会被打：代码换成 `hit` / `hit_big`，播完再换回 `daze`。所以 `hit` 从发晕的样子开始也要自然。

`bite` 什么时候播：游戏里宝箱怪的规矩叫"咬手"，你每打出一张带绿宝石的牌，它就咬一下，出手提前一回合。所以这一下要短、要脆，一眼看出"它咬了一口"。

## 3 口袋、磨石重画

- 大小、透明底、左上角 x 0–30、y 0–90 留空、`play` 600 毫秒，这些和第一版一样。
- 待机要很轻；`play` 要大。
- 动法照第 2 节：不用 `steps()`，所有部件同一组时间点。

| id | 现在的问题 | 改成 | 待机 | `play` 的关键时间点 |
|---|---|---|---|---|
| `card_art_bag` | 只是一只口袋，看不出"摸 2 张" | 袋口敞开，露出**两张牌背**的上半截，牌背照 `参考/现在的版本/card_back.svg` 缩小。口袋的搭扣还是一颗绿色方宝石 | 两张牌在袋口一起一伏，周期 2.5 秒 | 0 → 150（袋口一张）→ 300（第一张弹出、飞到画框上沿）→ 450（第二张跟着弹出）→ 600（袋口合回待机） |
| `card_art_stone` | 只是一只磨石轮，看不出"让宝石长大" | 轮上**正压着一颗宝石在磨**，磨的地方迸出光；旁边摆着磨亮了的红圆、绿方、蓝三角三颗小宝石 | 轮子慢转；磨的地方偶尔闪一下 | 0 → 150（轮子飞快转，火花迸出）→ 300 / 400 / 500（红、绿、蓝三颗小宝石依次亮起、变大一圈）→ 600（回到待机） |

两张都放在牌框里看：`参考/卡面结构.svg` 是拼法，`参考/现在的版本/` 里有牌框和原画窗底。在桌上只有 150 像素宽，要一眼认出来。

## 4 画风

照第一版，和 `参考/哥特画风/`：

## 6 验收怎么看

我们收到后会这样检查：
1. **逐格扫时间轴**：同一个动作里，各部件"开始变化、停住"的时刻全部重合，不重合的次数是 0。对照 2.3 节的关键时间表。
2. **幅度**够 2.2 节的下限。
3. **出框**：每 20 毫秒一帧，沿线条取点量，0 处出框。
4. **静止**：动画全关掉时，样子就是待机的样子，好看、不缺东西。
5. **游戏里看**：放进游戏打一仗，找三个不知道情况的人看 5 秒录屏，能说出"被打了""它咬我"。

自己交之前，请至少用 `预览.html` 把每个事件播一遍、查一遍出框。
