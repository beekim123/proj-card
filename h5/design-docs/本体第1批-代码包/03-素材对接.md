# 03 素材对接

`素材清单.json` 升到第 4 版，89 个素材。替换项目里的 `public/art-manifest.json`。美术拿的是同一份。

现有的读法（`img` / `inline`、`events`、`stay`、`idle` 静止版、`slots`、`tint`、九宫格、占位图、`?page=art`、播清单里没有的事件不报错）**全部照旧**。这一批只加下面这些。

## 1 新字段 `batch`

- `batch: "本体第1批" | "本体第2批"`：本体里美术哪一批交，代码不用管。
- 第二版剩下的 16 个（`v2: "第2批"`）还是占位图，这一批不动它们。

## 2 新素材（14 个）

| id | load | 大小 | 事件 / 其他 | 用在哪 |
|---|---|---|---|---|
| `ui_door` | inline | 320×480 | `open` 600（`stay`）；落地点 (160, 480) | 挑门（02 第 2 节） |
| `ui_reward_card` `ui_reward_shop` `ui_reward_heal` | img | 64×64 | | 门楣上的奖励牌子（放进 `ui_rule_sign` 的 `icon_slot`）、说明框 |
| `npc_knocker` | inline | 240×240 | `talk` 1200；`idle`；中心 (120, 120) | 开局选宝物画面上的老门环 |
| `card_art_hourglass` `card_art_seal` `card_art_shadow` `card_art_whistle` | inline | 176×188 | `play` 600 | 4 张新额外牌的原画 |
| `relic_start2` `relic_slow` `relic_first2` `relic_twice` | img | 96×96 | | 4 件新宝物 |
| `ui_node_door` | img | 64×64 | | 进度上"两扇门"的那一格 |

- 都还没画，**全部用占位图**，大小、事件、`stay` 和清单一致。
- 占位图要能分得清：
  - `ui_door`：一个拱门形的框 + 一块门板；`open` 时门板横向收窄到左边，露出后面的深色；
  - 奖励图标写一个字：`牌`、`坊`、`心`；
  - `npc_knocker`：一个圆 + 一个环，`talk` 时环上下动；
  - 额外牌原画写牌名；宝物写宝物名的前两个字；
  - `ui_node_door` 写 `门`。
- 奖励牌子用的是 `ui_rule_sign`（第二版的规矩牌子，现在也是占位图）：`rule_text` 写 `额外牌` / `工坊` / `回一颗心`。`回一颗心` 四个字放不下 30 号就缩到 24 号。

## 4 素材检查页 `?page=art`

- 更新到 89 个。新素材、新事件都能逐个播放。
- 筛选里加：本体第 1 批 / 本体第 2 批。
- `ui_door` 预览：并排摆两扇，一扇关着、一扇播 `open`；门前各放一只占位怪，门楣上各挂一块奖励牌子，看位置对不对（用 02 第 1 节 `doors` 的数）。
- `npc_knocker` 预览：旁边放一个说话框，点一下播 `talk`。

## 5 换美术不改代码

和上次一样，这条要测：

- 自己做一个假的新版 `ui_door.svg`（带 `open`），放进 `dist/art/`；
- 刷新后，挑门画面上的门是它，进门时播的是它的 `open`；
- 检查页里也换掉了；
- 没改代码。
