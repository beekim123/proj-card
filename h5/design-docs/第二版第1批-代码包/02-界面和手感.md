# 02 界面和手感

坐标都是设计像素：竖屏 1080×2160，横屏 1920×1080。新加的字段都放进 `src/layout/types.ts` 和两份布局表，`fit.ts` 跟着挪（规矩牌子跟着怪走，彩虹进度跟着伤害面板走，"能出彩虹"提示跟着手牌走）。

## 2 开局选宝物

- 阶段 `relic` 的画面：
  - 背景和战利品画面一样：桌子、怪的位置空着。
  - 标题横幅：`选一个宝物带进古堡`。
  - 三块牌子摆在 `loot.three` 的位置，大小和战利品牌一样，用 `ui_panel` 九宫格做底。每块从上到下：
    - 宝物图标 `relic_<id>`，96×96 放大 2 倍；
    - 名字（36 号）；
    - 效果文字（26 号，最多 3 行）。
- 和战利品一样**点两下才拿**：第一下选中抬起，第二下拿走。电脑按 1–3。
- 拿走后：图标飞到宝物栏，然后进第 1 仗，照现有的进场动画。
- 没有"不拿"按钮。

## 3 打仗画面

### 3.1 宝物栏

- 在 `relics` 位置排已有的宝物图标（这一批只有 1 个）。点一下弹窗看名字和效果。
- **宝物起作用时**（出牌结果的 `effects` 里有它的名字）：
  - 图标放大 1.3 倍再回来，200 毫秒，亮一下；
  - 同时这张牌下面出效果标签（3.4 节）。

### 3.2 规矩牌子

- 挂在 `ruleSign`，用 `ui_rule_sign`：
  - 代码在 `rule_text` 写规矩名；
  - 在 `icon_slot` 放 `rule_<id>` 图标。
- 发条兵：名字后面接发条圈数，用 `●` 和 `○`，比如 `上发条 ●●●○`；松完写 `发条松完`。
- 点牌子或点怪：弹窗显示怪的介绍 + 规矩名 + 规矩说明（01 第 2 节的文字）。宝石龙三条规矩都列出来，当前那条标"现在"。
- 规矩起作用时，下面几件事**同一刻**发生，不排队：

| 规矩 | 怪的动作 | 牌子 | 倒计时 | 声音 |
|---|---|---|---|---|
| 咬手 | `mon_chest` 播 `bite` | 抖一下 | 数字当场减 1，变红闪 300 毫秒，播 `ui_countdown` 的 `tick` | 咔（短促、低） |
| 抱红 | 不播 | 抖一下 | 不变 | 闷"噗"一声（红宝石伤害的位置） |
| 松发条 | `mon_soldier` 播 `unwind` | 圈数少一个 | 不变 | 咯噔（棘轮） |
| 发条松完 | `mon_soldier` 挂 `wound_down`，到下回合开始去掉 | 字变`发条松完` | 回到满值，变绿闪 300 毫秒 | 一串咯噔 + 一声泄气 |
| 敲钟 | `mon_clock` 播 `ring` | 抖一下 | 当场减 1，变红闪 | 当——（钟声，和凑白的声音叠在一起） |
| 换规矩（龙） | `mon_dragon` 播 `layer` | 播 `flip`，翻到一半换字和图标 | 不变 | 低吼 |

- 倒计时现在只在回合结束变，这一批改成**出牌当场就变**，撤回也要变回去。
- 倒计时 ≤ 1 时挂 `warn`（现有）。到 0 也挂 `warn`，数字写 `0`。

### 3.3 手牌提示

- 提示开着时：
  - **只有 `bestHintCard` 那一张**发光，上方写反应名（`凑白`、`顺色 · 倍率 ×2`……）。别的牌不发光、不写字。
  - 规矩、宝物的警告标签照样显示（下一条）。
- 警告标签**不管提示开没开都显示**，贴在牌上方：
  - `会挨打`：红底白字。`cardWarnings().attack`。
  - `松发条`：蓝灰底。`cardWarnings().unwind`。
  - 同时有两个，就排成两行。
- 拖牌预览，也就是拖到桌上还没松手时：
  - 预计伤害照旧；
  - 这张会改倒计时的话，倒计时旁边写 `3 → 2`；
  - 会挨打的话，倒计时整个变红、怪轻轻抖。
- 手牌大图（按住或停留出的那张）的说明里加一行规矩影响，例如 `咬手：出手提前 1 回合`、`抱红：红宝石算 0`。

### 3.4 桌面排的牌

- 牌下面的伤害数字改成**这张的总伤害**，也就是 `damage`，含彩虹和锤子。这样一排加起来等于"本回合"。
- 有加成的，在总数下面用小字（24 号）写加成，例如 `彩虹 +188,100`、`锤子 +1,700`。
- `effects` 里有东西的，在牌下面再加一行效果标签（24 号，一行最多 2 个，多了换行）：
  - 规矩：`抱红`、`咬手`、`敲钟`、`松发条`、`发条松完`、`换规矩`。都用旧铜色。
  - 宝物：`断一次不算`、`同色也翻倍`、`凑白 ×8`、`五色彩虹`。都用宝物的金色。
  - 抱红的那颗红宝石，算式里写 `红 0`；牌下面的数字照总伤害写。

### 3.5 彩虹进度

- 在 `rainbow` 位置排 6 个 `ui_rainbow_slot`。按 红 → 黄 → 绿 → 青 → 蓝 → 品红 排，染色用调色板里对应的混色。
- 亮哪几格看 `rainbowStatus().lit`：
  - 新亮的格播 `light`；
  - 链断了，亮着的全部播 `out`；
  - 出了彩虹，6 格一起闪 2 次，然后保持亮到回合结束。
- 有「五色彩虹」时 6 格照样摆，旁边小字写 `5 种就够`。
- **"这手能出彩虹"**：`rainbowStatus().ready` 为真时，`rainbowReady` 位置出一条提示条，文字是 `这手能出彩虹`，边框慢慢转彩虹色。`readyIds` 那几张手牌描一圈彩虹边。`ready` 变成假就收起。

### 3.6 心和回心

- 不拿战利品不再回心。战利品画面的"不拿"按钮文字改成 `不拿`，去掉回心的说明。
- 打赢精英：
  - 现在的"背包变大"横幅改成 `背包变大 · 心回满`；
  - 缺的心一颗一颗播 `gain` + `fx_heal`，间隔 150 毫秒；
  - 提示 `手牌上限 7 → 8，心回满了`。
- 有「多一颗心」时显示 4 颗心，`hearts` 的间距不变，往右排。

## 4 打击感

数字是第一版，集中放进一个 `FEEL` 配置，以后要调。

| 时机 | 做什么 |
|---|---|
| 每出一张牌 | 牌落到桌面排时往下压 6 像素再弹回，120 毫秒；出牌音（第 5 节） |
| 普通一击 | **顿帧 60 毫秒**：怪和特效的动画暂停 60 毫秒再继续，用 `Animation.pause()` 或 `animation-play-state`，输入不锁。怪**闪白**：`filter: brightness(2.2)` 一帧（约 16 毫秒），80 毫秒内退回。**整只怪被打退**：怪的外层元素往后上方移 16 像素（50 毫秒到位），停 80 毫秒，250 毫秒弹回并带一次过头。伤害数字从 0.6 倍弹到 1.3 倍，再落到 1 倍，280 毫秒 |
| 大击：这张伤害 ≥ 怪满血的 10%，或凑白、彩虹、锤子 | 顿帧 120 毫秒；闪白保持 80 毫秒；整只怪被打退 32 像素；**震屏中档**；怪播 `hit_big` |
| 倍率翻倍：顺色、凑白、放大镜 | 倍率牌绕 X 轴翻一下（`rotateX` 0 → 180 → 360，300 毫秒），同时放大到 1.25 倍；配"翻倍"音。+1 时只放大 1.1 倍 |
| 凑白 | 两张牌之间播 `fx_white`，放大 1.3 倍；震屏中档 |
| 打穿 | 打穿那张的所有动画按半速播 300 毫秒（`playbackRate = 0.5`），再恢复；怪挂 `daze`；震屏大档 |
| 彩虹 | 链上的牌从左到右依次亮一下，每张间隔 60 毫秒；然后全屏 `fx_rainbow` 放大 2 倍；震屏大档；"彩虹 +…"字用彩虹渐变（第 6 节第 7 条） |
| 怪出手 | 怪播 `attack`。同时代码让**整只怪扑向镜头**：0–250 毫秒不动（美术在做蓄力）；250–330 毫秒外层元素放大到 1.3 倍、往下移 40 像素，压过桌沿；停到 450 毫秒；800 毫秒前退回。第 330 毫秒是打中的一刻：心在原位播 `lose`，整屏四周压暗边（`vignette` 径向渐变，0 → 0.55 → 0，500 毫秒），震屏大档 |

- **分工**：怪自己的姿势（缩、扑、张嘴、换脸、碎片）是美术画在 SVG 里的，每帧都不出画框；**整只怪的位移和缩放**（被打退、扑向镜头）由代码对怪的外层元素做，时间点和美术的事件对齐（`hit` 第 50 毫秒到位，`attack` 第 330 毫秒打中）。
- **震屏三档**，现有的 `shake` 改成三档：

  | 档 | 幅度 | 时长 |
  |---|---|---|
  | 小 | 3 像素 | 150 毫秒 |
  | 中 | 8 像素 | 250 毫秒 |
  | 大 | 14 像素 | 380 毫秒 |

  设置里加"震屏：开 / 关"。
- **伤害数字分三档大小**：
  - 不到 1 万：44 号；
  - 1 万到 100 万：60 号；
  - 100 万以上：80 号，并且金色斜体（现有样式）。
- **总时长上限**：一张牌的顿帧最多 120 毫秒。连着快出牌时，上一张的反馈没播完就直接叠下一张，不排队、不锁输入。
- 设置里加"动画速度：正常 / 快"。快 = 顿帧减半、慢放取消。

## 5 声音

全部用 WebAudio 现场合成，不加音频文件。一个 `src/ui/sound.ts` 管：总音量、开关（设置里），以及下面这些音。

| 音 | 什么时候 | 怎么合成（参考，可以调） |
|---|---|---|
| 出牌音 | 每出一张 | 短拨弦（三角波 + 很快的音量包络，120 毫秒）。**同一回合每出一张升一级**，按五声音阶 C D E G A 往上走，到顶后停在最高音。下一回合回到最低 |
| 翻倍 | 倍率翻倍 | 出牌音上面叠一个高八度的短音 |
| 凑白 | 凑白 | 一声明亮的和弦（三个音一起），200 毫秒，带一点混响尾 |
| 彩虹 | 彩虹 | 6 个音快速往上琶音（每个 60 毫秒），最后一个长一点 |
| 打中 | 每次打中 | 低频"咚"（正弦 80→40 Hz 下滑，100 毫秒）+ 一点噪声；大击音量更大、更长 |
| 打穿 | 打穿 | 更重的"咚" + 往下滑的噪声扫 |
| 心碎 | 掉心 | 玻璃碎（高频噪声短脉冲 ×3） |
| 回心 | 回心 | 两个往上的柔和音 |
| 咬手 / 抱红 / 松发条 / 敲钟 / 换规矩 | 见 3.2 节 | 咔：短方波；噗：低通噪声；咯噔：两下极短的噪声；当：正弦 + 泛音，长衰减；吼：低频锯齿 + 颤音 |
| 按钮 | 点按钮 | 很轻的"嗒" |

- 第一次点击或拖牌以后再创建 `AudioContext`。切到后台时暂停。
- 设置里：声音开 / 关、音量（3 档）。记进 `gemcard.settings`。

## 6 修 7 处界面问题

1. **提示条排队**：现在 `toast` 是排着一个一个播，破防提示会晚一两秒，还盖在怪脸上。
   - 改成新提示直接顶掉旧的，不排队。
   - 提示的位置挪到 `banner` 上沿，不压怪的脸。
   - 出牌过程中的事，比如升级、规矩起作用，不再用提示条，用 3.2、3.4 节的标签和动作。
2. **牌下的数字加起来不等于"本回合"** → 3.4 节：写总伤害。
3. **"本回合"滚动第一帧闪负数**（截到过 −11）：滚动从**屏幕上正在显示的数**滚到新数，永远不显示负数。撤回时往下滚也一样。
4. **首领打穿后按钮还写"拿战利品"** → 第 6 仗打穿后按钮写 `打赢了！`，点了进胜利结算。
5. **8 张手牌时最左一张出屏**：手牌扇形按张数收紧间距，保证最左、最右两张整张都在舞台里。7、8、9 张都要测（口袋能让手牌超过上限）。
6. **7 张牌里 6 张带提示，等于没提示** → 3.3 节：只标最好的一张。
7. **彩虹字被盖成金色**：彩虹的飘字和横幅用彩虹渐变（`background-clip: text`）。加样式时注意别被大伤害的金色样式盖掉。
