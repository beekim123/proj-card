## 模拟器怎么用

```
cd design-docs/模拟
node 跑第二版.mjs        # 第二版 6 仗
node 跑本体.mjs 第一批   # 本体第 1 批（只有第一幕），几十秒
node 跑本体.mjs 全部     # 核对 + 第一批 + 三幕 + 加码，4 核大约 25 分钟
```

本体的数值都在 `内容表.mjs`：血量 `HP`、整局配置 `FULL`、第 1 批配置 `BATCH1`、加码倍数 `TIERS`、两种拿法 `PICK_RANDOM` / `PICK_SMART`。

用真规则跑：在仓库根目录先 `npx esbuild src/rules/index.ts --bundle --format=esm --platform=node --outfile=/tmp/gcsim/rules.mjs`，再照 `核对第一版-真规则.mjs` 写机器人。

## 其他在仓库里的

- `spec/`：第一版的规则说明和布局图（规则以 `src/rules/` 代码为准）。
- `public/art-manifest.json`：现在的素材清单（75 个）。
- `art-source/`：画风规则、各批交回的美术原样、验收页。
