# 第二版设计稿：手感 + 每局不一样

2026-11-10。依据：Fable 的评估（`../制作评估-2026-11-10.md`）、你给的 Steam 卡牌调研、机器人模拟（`模拟/`）。

**已定（2026-11-10，用户："都按你的来"）。** 第 9 节 7 件事全部照我的倾向。第 1 批代码包、美术包在 `第1批/`。

## 一句话

现在的问题有两个：
- **动起来发软**：没有打击感、没有声音，待机在抖。
- **学会排顺序就没难度**：会规划的打法 100% 通关，几乎不挨打。

这一版两件一起治：
- **手感**：打击反馈、声音、怪的动作返修。
- **每局不一样**：怪有自己的规矩，开局选一个宝物，战利品和回心换个给法。

色光牌的底层规则一条不动。

## 这一版改什么

## 1 怪的规矩

每只怪只有一条规矩，写在怪头顶的牌子上。一句话说清楚，一眼能看到它在起作用。

| 怪 | 规矩 | 规则 | 画面上看到什么 |
|---|---|---|---|
| 宝箱怪 | **咬手** | 每打一张带绿的牌，它出手提前 1 回合 | 打出带绿的牌，宝箱"咔"地咬一下，倒计时当场减 1 |
| 布偶熊 | **抱红** | 红宝石打它算 0（倍率照涨、反应照算、照样成长） | 熊怀里抱着红宝石；红宝石的伤害数字显示灰色 0 |
| 发条兵 | **上发条** | 出手倒计时 2；每打一张带蓝的牌，它的发条松一圈；松完 4 圈，**这次出手作废**，下回合发条重新上满 | 背后的钥匙每松一圈转一下，松完那一下垮下来 |
| 老座钟 | **敲钟** | 每凑白一次，钟响一下，出手提前 1 回合 | 凑白时钟锤敲一下，"当"一声，倒计时减 1 |
| 宝石龙 | **三层脾气** | 三层血，每掉一层换一条规矩：先抱红，再咬手，最后敲钟 | 掉层时龙吼一声，头顶牌子翻面换规矩 |

**细节**
- "出手提前 1 回合" 就是倒计时减 1，最低减到 0。回合结束时倒计时到 0，它就打你，一回合最多打一次。
- 已经打穿的怪不再咬手、敲钟。
- 手牌提示加一种红色标签 **"会挨打"**：这张一打下去，回合结束就会被打。发条兵的蓝牌标 **"松发条"**。
- 原来的韧性条、"削韧"标签、破防 ×1.5 全部去掉，只留在发条兵身上，改成"松发条"。

**为什么这样定**
- 两只怪拿倒计时做取舍：咬手按颜色，敲钟按反应。这就是"贪连击还是先保命"，调研里 Wildfrost 的"看见倒计时、预判危险"也是这种乐趣。
- 抱红是限制伤害：红牌最好当接链的牌，放在倍率还低的时候打。
- 上发条是帮你的规矩：蓝牌打够数，就躲过一次挨打。新手最受用。
- 首领不教新东西，考你前面学过的，这是调研里说的"破解"。

**模拟结果**（会规划的打法，第一版 → 第二版）：
- 宝箱怪：每回合平均留 0.7 张牌不打（以前是 0），躲着绿牌。
- 老座钟：每回合凑白从 2.3 次降到 1.9 次，开始挑时机凑。
- 布偶熊、发条兵：高手的打法变化不大。抱红主要是扣伤害；松发条主要是救新手，跟提示打的每局能靠它躲掉 1.7 次挨打。

## 2 开局宝物

开局从 3 个里选 1 个，整局有效。共 6 个，名字就是效果：

| 宝物 | 效果 | 新手通关 | 高手通关 / 每局挨打 |
|---|---|---|---|
| 同色也翻倍 | 同色也让倍率翻倍（原来只 +1） | 11% | 94% / 1.1 次 |
| 断一次不算 | 每回合第一次没反应，算作顺色 | 10% | 94% / 1.3 次 |
| 凑白 ×8 | 凑白从 ×5 变成 ×8 | 19% | 98% / 0.9 次 |
| 五色彩虹 | 顺色连满 5 种颜色就出彩虹（原来要 6 种） | 8%（但 15% 的局能见到彩虹） | 98% / 0.5 次 |
| 多一颗心 | 心上限 4 颗 | 17% | 100% / 1.8 次 |
| 宝石长得快 | 宝石 8 次切好、24 次闪光（原来 15、45） | 11% | 96% / 1.1 次 |

- 这张表是"这一局固定带这个宝物"的结果。对照：不带宝物时，新手 8%，高手 84% / 1.8 次。
- **试过但砍掉的**：
  - 多一张手牌：新手通关率从 11% 跳到 79%，太强。精英已经给 +1 手牌了。
  - 开局倍率 2：等于全程伤害 ×2，也太强。
  - 打穿后伤害 ×2：对输赢没影响，留给以后刷分用。
- 为什么放在开局：一局只有 6 仗，开局就选，第一回合打法就不一样。调研里"成长要看得见因果"也是这个意思：宝物的效果每次触发都要标出来，比如牌下面写"断一次不算"。

## 3 战利品和回心

- **现在**：3 选 1 额外牌；不拿就回 1 颗心。
- **问题**：模拟出来，"掉了血就回心、满血才拿牌"通关 96–98%，比一直拿牌（66–71%）高得多。正确答案永远一样，这不算选择。
- **改成**：
  - 战利品只有额外牌，3 选 1（超杀 ≥10 时 4 选 1），可以不拿，不拿什么也不给。
  - **打赢精英（第 3 仗）回满心**，手牌 +1 照旧。
- **效果**：回心变成固定的歇脚点。前 3 仗和后 3 仗各有 3 颗心，后半程不能再靠回心续命。
- 备选是 Fable 的倾向：回心当作战利品里的一个选项。缺点是"掉血就选回心"照样是唯一正确答案。

## 4 彩虹看得见

- 本回合数字旁边加一个六格进度，按 红 → 黄 → 绿 → 青 → 蓝 → 品红 排。顺色每接上一种新颜色就亮一格，断了就灭。
- 手牌里六种颜色齐了，提示 **"这手能出彩虹"**，6 张牌描一圈彩边。顺序让玩家自己排，进度环就是答案。
- **模拟**：新手能见到彩虹的局从 3% 涨到 65%。通关率不变，彩虹是一次"哇"，不是过关的钥匙。
- 彩虹字恢复成彩虹色。现在被后加的样式盖成了金色。

## 5 手感（代码）

数字照 Fable 给的，美术只管姿势，时间和整屏归代码。

| 时机 | 反馈 |
|---|---|
| 每出一张牌 | 音阶升一级（同一回合越打越高）；牌落桌时轻微下压 |
| 普通一击 | 顿帧 60 毫秒（画面冻住）；怪闪白 1 帧；伤害数字弹出放大 1.3 倍再落定 |
| 大击（本张伤害 ≥ 怪满血的 10%，或凑白、彩虹、锤子） | 顿帧 120 毫秒、闪白 80 毫秒、震屏中档、播怪的 `hit_big` |
| 倍率翻倍 | 倍率牌整块翻一面并放大，配一声和普通 +1 不同的音 |
| 凑白 | 两张牌之间炸一圈白光，震屏中档 |
| 打穿 | 慢放半拍（0.3 秒内速度降到一半），怪保持发晕姿势 |
| 彩虹 | 六张牌依次亮起，全屏一次爆发，震屏大档，专属音效 |
| 怪出手 | 怪蓄力 → 冲出 → 心在原位碎掉 → 屏幕四周压一圈暗边 |
| 咬手、敲钟、松发条 | 各有一声短音效，倒计时数字当场跳动 |

- 伤害数字位数越多字越大，4 位、5 位、6 位以上分三档。
- 声音这一版用免费音效库或程序合成，先有再说。

## 6 美术

### 返修已有素材（规则照 Fable 的硬性规则）

1. 同一个动作里，所有部件在同一个时间点换姿势，不允许各动各的。
2. 待机不用 `steps()`，改成顺滑的呼吸，主体上下 6–10 像素，周期 2–3 秒。线条抖动去掉。
3. **受击**：50 毫秒内到最大位移，停 80 毫秒，250 毫秒弹回，带一次过头。位移至少怪宽的 8%，大击至少 15%，大击换脸、崩碎片。
4. **出手**：后缩蓄力 250 毫秒，80 毫秒冲到 1.3 倍大并压过桌沿（下移至少 40 像素），停 120 毫秒，再退回。
5. 会动的组不挂滤镜；做旧纹理放在单独一个不动的层。
6. 部件名、轴心、落地点、打击点不变。

**验收**：
- 逐格扫时间轴，同一动作里各部件"变化的时刻"完全重合，不重合 0 次。
- 幅度够下限。
- 找三个不知情的人看 5 秒录屏，能说出"被打了"或"它打我"。

**顺序**：先只返修宝箱怪当样稿（待机、受击、出手），过了再做另外四只。口袋、磨石的原画重画一起带上：口袋露出两张牌，磨石正在磨一颗宝石。

### 新画的（为规矩和宝物）

| 素材 | 内容 |
|---|---|
| 规矩牌子 | 挂在怪头顶的小木牌，代码写字；翻面动作（龙换规矩用） |
| 规矩图标 ×4 | 咬手、抱红、上发条、敲钟 |
| 宝箱怪 `bite` | 合盖一咬，0.3 秒 |
| 老座钟 `ring` | 钟锤敲一下，0.4 秒 |
| 发条兵 `unwind` | 钥匙转一圈 0.3 秒；`wound_down` 松完垮下 0.6 秒，一直保持到下回合 |
| 布偶熊 | 现有造型里怀里抱的宝石要是红的（核对一下，不对就改） |
| 宝石龙 `layer` | 掉层时吼一声，0.8 秒 |
| 宝物图标 ×6 | 古堡里的小物件，宝石色只用在跟效果有关的地方 |
| 彩虹进度 | 六格小宝石槽，亮和灭两种状态 |

## 7 界面 7 处（Fable 找到的）

1. 提示条排队，破防提示晚一两秒才出，还盖在怪脸上 → 新提示直接顶掉旧的，位置挪到怪的上方。
2. 牌下面的数字不含加成，加起来不等于"本回合" → 牌下面写这张的总伤害，加成写成小字。
3. "本回合"滚动的第一帧会闪负数 → 从旧值滚到新值，不从 0 算差值。
4. 首领打穿后按钮还写"拿战利品" → 改成"打赢了"。
5. 8 张手牌时最左一张出屏 → 手牌扇形按张数收紧。
6. 7 张牌里常有 6 张带提示标签，等于没提示 → 只标最好的一张，再加"会挨打"这类警告。
7. 彩虹的字被盖成金色 → 恢复彩虹色。

## 8 数值和模拟

模拟器在 `模拟/`，规则照游戏代码 `src/rules/` 写。先用第一版规则跟真规则对过：跟提示打的四种拿法，模拟 90/66/76/98%，真规则 88/71/73/96%。

三种打法代表三种玩家：
- **随手丢**：完全不看。
- **跟提示**：照牌上的提示一张张打，会看"会挨打"标签。代表新手。
- **整手规划**：每回合把整手牌的顺序算到最好。代表高手。

| | 随手丢 | 跟提示 | 整手规划 | 高手每局挨打 | 高手见彩虹 |
|---|---|---|---|---|---|
| 第一版（现在） | 0% | 98% | 100% | 0.4 次 | 70% |
| **第二版（全部改动）** | 0% | 12%（加彩虹提示后 65% 的局能见到彩虹） | 93% | 1.3 次 | 63% |
| 第二版去掉怪的规矩 | — | 65% | 100% | 0.3 次 | — |
| 第二版去掉开局宝物 | — | 8% | 84% | 1.8 次 | — |
| 第二版战利品照旧 | — | 17% | 100% | 1.0 次 | — |

- 第二版里，跟提示打的大多输在第 5、6 仗，也就是能一路打到首领面前。高手偶尔输在首领。
- 血量没改，还是 2万 / 4万 / 10万 / 30万 / 60万 / 150万。如果第 4–6 仗乘 0.9 / 0.85 / 0.8：跟提示 23%，高手 97%、每局挨打 0.9 次。
- 机器人不是真人。"跟提示"那个机器人永远不会学，真人打几局应该会往高手那边靠。最后的血量要等真人试玩再定。

## 附：调研文档对这一版的影响

你给的《Steam 卡牌游戏玩法与玩家体验调研》里，跟这一版直接相关的四条：

- **"坏牌打活"和"破解"**：怪的规矩就是这个，前提是规则看得见、有办法应对。所以每条规矩都配了画面和提示标签。
- **"看见敌人的倒计时、预判危险"**（Wildfrost）：咬手、敲钟都是拿倒计时做取舍。
- **"成长要看得见因果"**：所以要修牌下数字对不上的问题，宝物每次触发也要标出来。
- **"连锁爆发的失效条件是自动播放过长"**：顿帧加在一起不能太长。一回合 8 张牌，反馈总时长控制在 3 秒以内，以后加"快进"。
