4. **占位素材契约**：34 个 SVG 独立生成并用 XML 解析器成功解析；检查 viewBox、部件、事件与 currentColor；常规 ID/url/href/xlink:href/style 边界与实例隔离测试通过。
5. **本地浏览器脚本语法**：browser_smoke.py 通过 Python 语法检查。注意这不是浏览器执行结果。

主工程的 npm test、typecheck、build、zip 检查由集成验收另行记录；此处不重复冒认执行。

- 主布局坐标集中在 portrait.ts / landscape.ts；卡面读取清单布局；URL 布局优先于偏好和自动方向。
- 四类弹窗、设置保存、重新开始确认、Pointer Events、快捷键、拖拽取消分支、预览、调试发牌、素材检查页均有对应实现。

以上只证明代码路径存在并经审阅，不证明浏览器中的外观、交互或性能通过。
