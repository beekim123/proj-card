# 美术替换测试夹具

`dummy.svg` 是人工测试文件，不是正式美术。它保留素材清单要求的 viewBox、固有尺寸、部件 ID、待机 / hit / hit_big 事件，把木桩头部改为清单中的蓝色，便于确认替换。

云端已完成：生成合法 SVG，34 项占位 XML 检查、ID 隔离及事件定时单元测试。当前云环境不支持运行浏览器，此夹具还未在真实浏览器验证。

本地测试步骤：

1. 在项目根目录运行 `npm ci`、`npm run build`。
2. 将本目录的 `dummy.svg` 复制到 `dist/art/dummy.svg`。若 `dist/art/` 不存在，先创建目录。
3. 使用任意静态服务器打开 `dist/`。不要使用 `file://` 直接双击。
4. 刷新游戏，木桩头部应为蓝色；出牌后仍应播放受击动画。
5. 打开 `?page=art`，`dummy` 的来源应显示“美术”，点击 `hit` 和 `hit_big`，确认动画可重复播放。
6. 同页点击 `fx_hit` 的“同时播放两个实例”，确认两种颜色特效各自正常。
7. 删除 `dist/art/dummy.svg` 后刷新，两页应恢复“占位”木桩。以上复制和删除步骤不需要重新构建，也不改任何源代码。

若开发服务器测试，请临时复制到 `public/art/dummy.svg`，测试结束后移除；不要把夹具当成正式美术交付。
