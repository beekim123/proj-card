# design-docs：设计文档索引

给接手设计本体的人看。游戏代码在仓库根目录，美术在 `public/art/` 和 `art-source/`。

| 文件 | 是什么 |
|---|---|
| `设计稿.md` | 第二版为什么这么设计：怪的规矩、开局宝物、模拟数据、已拍板的事 |
| `制作评估-2026-11-10.md` | 上一轮对试玩版的评估（只看玩法、手感、数值那几节；平台、引擎部分现在不用管） |
| `Steam卡牌游戏玩法与玩家体验调研.md` | 同类游戏的玩法和玩家体验调研，设计时参考 |
| `模拟/` | 规则模拟器 `sim.mjs`，加几种机器人。`node 跑第二版.mjs` 直接跑；`核对第一版-真规则.mjs` 是用真规则代码核对的写法 |
| `第二版第1批-代码包/` | 发给开发的需求包，**代码包的格式样板**：00 开发说明、01 规则改动、02 界面和手感、03 素材对接、04 验收清单 |
| `第二版第1批-美术包/需求.md` | 发给画手的需求包，**美术包的格式样板** |

## 模拟器怎么用

```
cd design-docs/模拟
node 跑第二版.mjs
```

用真规则跑：在仓库根目录先 `npx esbuild src/rules/index.ts --bundle --format=esm --platform=node --outfile=/tmp/gcsim/rules.mjs`，再照 `核对第一版-真规则.mjs` 写机器人。

## 其他在仓库里的

- `spec/`：第一版的规则说明和布局图（规则以 `src/rules/` 代码为准）。
- `public/art-manifest.json`：现在的素材清单（75 个）。
- `art-source/`：画风规则、各批交回的美术原样、验收页。
