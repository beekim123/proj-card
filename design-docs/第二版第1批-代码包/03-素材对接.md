# 03 素材对接

`素材清单.json` 升到第 3 版，75 个素材。替换项目里的 `public/art-manifest.json`。美术拿的是同一份。

现有的读法（`img` / `inline`、`events`、`stay`、`idle` 静止版、`slots`、`tint`、九宫格、占位图、`?page=art`）**全部照旧**。这一批只加下面这些。

## 1 新字段 `v2`

- `v2: "第1批" | "第2批"`：第二版里美术哪一批交，代码不用管。
- `status` 多了两个值：`返修`、`重画`。代码也不用管，id、尺寸、部件都不变。

## 2 已有素材的新事件

| 素材 | 新事件 | 毫秒 | 什么时候播 |
|---|---|---|---|
| `mon_chest` | `bite` | 300 | 咬手起作用 |
| `mon_soldier` | `unwind` | 300 | 松发条 |
| `mon_soldier` | `wound_down`（`stay`） | 600 | 发条松完；挂到下回合开始 |
| `mon_clock` | `ring` | 400 | 敲钟 |
| `mon_dragon` | `layer` | 800 | 换规矩 |

- **占位图要有这些新事件**：
  - 现有占位怪的做法照旧，加上新事件。
  - 现在项目里的真美术 `mon_chest` 等还没有 `bite`：代码播一个没有的事件时，**不能报错、不能卡住**。按清单里的毫秒数等完，就当播过了。这一条要测。
- 美术交回的新版会带上这些事件，拷进 `art/` 就生效。

## 3 新素材

| id | load | 大小 | 事件 / 其他 | 用在哪 |
|---|---|---|---|---|
| `ui_rule_sign` | inline | 280×88 | `flip` 400；`slots.rule_text`；`icon_slot` 是空组，代码放图标 | 规矩牌子（02 第 3.2 节） |
| `rule_bite` `rule_hug` `rule_wind` `rule_bell` | img | 64×64 | | 牌子上的图标、规则弹窗 |
| `relic_same` `relic_once` `relic_white` `relic_rainbow` `relic_heart` `relic_grow` | img | 96×96 | | 宝物栏、选宝物、弹窗 |
| `ui_rainbow_slot` | inline | 48×48 | `light` 300（`stay`），`out` 300；`tint` | 彩虹进度一格，代码按颜色染 |

- 都还没画，**全部用占位图**，大小、事件、`stay`、`slots`、`tint` 和清单一致。
- 占位图要能分得清：
  - 规矩图标写规矩名的第一个字；
  - 宝物写宝物名的前两个字；
  - 彩虹格是一个圆槽，`light` 时用 `currentColor` 填满。
- `ui_rule_sign` 的 `rule_text` 槽在 (140, 52)，30 号字；`icon_slot` 在左边，约 (20, 16) 到 (76, 72)。

## 4 宝物和规矩的 id 对照

| 规则里的 id | 图标素材 |
|---|---|
| 规矩 `bite` / `hug` / `wind` / `bell` | `rule_bite` / `rule_hug` / `rule_wind` / `rule_bell` |
| 宝物 `same` / `once` / `white` / `rainbow` / `heart` / `grow` | `relic_same` / `relic_once` / `relic_white` / `relic_rainbow` / `relic_heart` / `relic_grow` |

## 5 素材检查页 `?page=art`

- 更新到 75 个。新事件、新素材都能逐个播放。
- 按 `v2` 分组的筛选：全部 / 第 1 批 / 第 2 批。
- `ui_rule_sign` 预览时，在 `rule_text` 槽里写"咬手"、在 `icon_slot` 放 `rule_bite`，看字和图标的位置对不对。
- `ui_rainbow_slot` 预览时，6 种颜色各摆一个。

## 6 换美术不改代码

和上次一样，这条要测：
- 自己做一个假的新版 `mon_chest.svg`，带 `bite` 事件，放进 `dist/art/`；
- 刷新后，宝箱怪咬手时播的是它；
- 检查页里也换掉了；
- 没改代码。
